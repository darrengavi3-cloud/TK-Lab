# 人物誌 P1：研究核心與只讀預覽

## 狀態與邊界

基線：`c2cef1ce3a21eb503ae0c5c7e5415173810cc39e`。

本批次是第一階段的**可執行只讀切片**，不是五大維度全部完成，也不是新資料庫已上線。新增領域模型、驗證器、保守舊資料橋接及擁有者專用預覽／校驗 API。沒有新增研究資料寫入、資料庫遷移、管理表單或閱讀端投影；沒有改動歷史資料、既有 ID、主表修訂或已發布快照。程式只有在後續合併及部署後才會提供新端點。

舊 `Appointment.date`、`holdsOfficeInYear`、既有閱讀端的年代解釋本輪不變。新的嚴格時序規則只用於 `domain/prosopography` 與研究預覽，避免未經逐項採擇便改寫原有成果。

## 已實作的對象

| 對象 | 本批次行為 |
|---|---|
| `OfficeTenure` | 一次任職的穩定身份；實任、起點、終點、連續性及見任各自採擇說法。 |
| `CareerEvent` | 任命、赴任、轉任、免官、復拜等事件；可關聯多次任職；相對先後不得成環。被俘、投降與死亡分開。 |
| `Claim` | 對特定任職或事件的一項說法；區分直接記載、推定與尚未分解的舊記錄。 |
| `EvidenceLink` | 鎖定來源 ID、修訂號與 SHA-256；支持與反證分開。 |
| `FactualConflict` | 同一對象、同一問題的相左說法；不覆蓋、不平均、不當成確定結論。 |
| `TextualVariant` | 固定來源版本中的具體讀法；驗證原文精確包含讀法，不以規範化文字替代。 |

這是按人物載入的研究圖，不是新的關係式持久化表。制度版本引用目前只做格式檢查並回報未核定警示；官職版本字典、地理分期、宗族、選任、評品、爵位與食邑尚待接管。來源依舊沿用現有 `Source` 修訂；作品／版本／見證／轉引鏈尚未另立實體，兩個修訂不自動代表兩份獨立史料。

## 年代與在任判斷

`HistoricalTime` 保留原紀年、年號、政權語境、干支及推定依據。最早／最晚年份是**同一事件或端點的可能範圍**，不是任期長度。負數為公元前，正數為公元後；第零年、小數年和越界值不接受，未知用 `null`。

研究查詢分為 `attested`（該年見任）、`continuous`（有證據支持連續在任）、`possible`、`unknown`、`not-held`、`outside` 與 `excluded`。只有前兩類的 `definite` 為真。

- 「某年間授官」不自動變成「整段時間在任」。連續任期須獨立採擇實任、起點、終點與連續性，且相關說法有支持證據、沒有登記反證或衝突。
- 起訖各有範圍時，只在最晚可能始任至最早可能終任之間斷言連續在任。推定年代與待考／存疑說法不能產生確定名錄。
- 某年見任不外推鄰年。未知終點不以死亡、最後見載、下一官職或政權終結補齊。互不相容的採擇拒絕並提示保留異說。
- 史實判斷、工作流程、顯示政策互相獨立；整理為 ready 不構成史實核定。驗證是結構與證據完整性檢查，**不代表程式已核實引文的歷史含義**。

## 舊資料橋接

`legacyResearchPreview` 以固定目錄水位讀取人物和任官修訂，逐項驗證摘要，保留原 ID、官名、任職性質、政權、轄區、年代及既有判斷。舊資料只生成 `legacy-record` 未解釋說法；不自動填入始任、終任、實任或新事件。

原 `variant` 引用轉為 `unclassified-variant` 並警示待分辨。已登記互證或未就的舊處置仍保留，不按同名同官自動合併、不改變現有閱讀端排除政策。人物層引用也被釘選，尚未細分姓名或親族說法。

預覽 manifest 包含目錄水位、人物 ID、實際使用的原記錄修訂與史料修訂、圖摘要。後出的資料不改變舊水位結果。這個 manifest **不是發布候選或部署回執**。

## API

端點接在原有 `/api/admin/` 路由，先執行原 owner 身份驗證；POST 另經同源及 `x-catalogue-request: 1` 校驗。無公開研究路由，回應均為 `no-store`。沿用原管理路由對 DB/R2 環境的要求。

```text
GET /api/admin/research/people/<encodeURIComponent(Person_ID)>?watermark=<N>
POST /api/admin/research/inspect
```

GET 未指定水位時只捕捉一次當前水位；指定 `0` 不等同最新版。未知人物、未來水位、缺失或摘要不符的固定來源會失敗，不以新版替代。

POST 內容：

```json
{
  "watermark": 3,
  "graph": {"model": 1, "personId": "person:example", "tenures": [], "events": [], "claims": [], "evidence": [], "factualConflicts": [], "textualVariants": []},
  "year": 200
}
```

以上是格式示例，不是實際人物資料。`graph` 可使用 GET 回傳的內容，再逐項整理；`year` 可省略。回應明示 `readOnly: true`、`persisted: false`。校驗不保存修改，不切換 active release，也不產生已採用的歷史結論。

單次圖上限 5000 項，單次預覽最多釘選 200 個來源修訂，HTTP 內容沿用 1 MB 限制。當前適配器仍讀取既有目錄快照再按人物篩選，**尚未完成大資料量的索引查詢及效能驗收**。
