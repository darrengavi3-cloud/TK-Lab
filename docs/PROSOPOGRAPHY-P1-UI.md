## 本次修改

新增 `/admin/research` 頁面及既有管理後台的入口。頁面沿用 owner 身份檢查；GET／HEAD 返回不快取的私有 HTML，HEAD 無正文。原有研究及閱讀端路由保持不變。

介面使用既有兩個 API：

- `GET /api/admin/research/people/:id?watermark=...`
- `POST /api/admin/research/inspect`

搜尋人物後按穩定 ID 選擇，同名人物分列。可指定目錄快照及查詢年份；年份查詢固定使用剛讀到的圖和快照，並核對返回的 `graphDigest`，不混用不同版本。原任官、原紀年、考證提示及固定版本引文分開呈現。

原文只作文字呈現，不執行 HTML。所展示的是原始讀取結果，**不是已採擇的新人物官歷**。未解譯資料仍顯示為未解譯，不從舊起訖擅自認定連續在任。

進階 JSON 草稿可校驗，但不保存、不建立資料修訂、不發布。草稿校驗結果另列，不覆蓋上方原始預覽與引文；匯出包含獨立的 `originalPreview`、`originalPresence` 和 `validatedDraft`，避免舊引文為新草稿背書。未校驗草稿不能匯出，已校驗但未匯出的草稿仍提示離頁風險。JSON 解析或服務端校驗失敗時保留草稿。

本次沒有新增編輯表單、寫入 API、D1 schema、歷史資料遷移、閱讀投影或部署。新頁面只有在後續合併並部署後才會出現於線上。
