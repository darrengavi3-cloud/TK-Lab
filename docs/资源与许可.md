# 资源与许可

本地项目将运行所需代码和地图数据固定在项目目录中，避免 CDN、WorkBuddy 发布页或 GitHub 原始文件失效时导致页面打不开。

| 资源 | 本地版本或来源 | 用途 |
|---|---|---|
| Vue | 3.5.39 | 页面响应式框架 |
| Element Plus | 2.11.4 | 表单、弹窗与基础组件 |
| GoJS | 3.1.10 | 职官树与组织图 |
| SheetJS xlsx | 0.18.5 | Excel 导入导出 |
| Leaflet | 1.9.4 | 历史地图画布 |
| Zhou Dadudu / Threekingdoms Archive | 本地快照 | 州郡边界与水系几何 |
| 三国形势图脚本 | WorkBuddy 项目 q71T7ZIe9O6xmZrTj3ldoy 的本地快照 | 地图图层、标记、路线与面板 |

Vue、Element Plus、GoJS、SheetJS、Leaflet 的许可证分别以各上游项目声明为准。州郡边界与水系在原地图中标注为 CC BY-NC-SA 4.0；本项目保留署名与原数据来源。

`data/asset-manifest.json` 记录所有本地运行资源的文件大小与 SHA-256，可用于检查复制、备份或后续修改后是否缺件。
