# V32 素色底图世界背景与缓存启动策略

检查日期：2026-08-06

## 本轮问题

- `terrain` 原来只加载 `assets/map/tiles/paper.svg`，纸色瓦片没有世界陆地、国家轮廓或国名；切换到素色地形后，域外国家与海面同色，看起来像“国家消失”。
- 启动恢复弹窗依赖 `beforeunload` 清除会话标记。刷新、嵌入地图 iframe 或浏览器异常退出时该事件不保证执行，旧标记会把下一次正常打开误判为异常退出。
- 单文件地图 srcdoc 中曾有一条旧 CSS 规则强制把周边族群矢量边界设为透明，导致参考图需要的浅色实线边界在便携版中消失。

## 实现

- 新增 `assets/map/data/geo-world-context.js`：由 Natural Earth 1:110m Admin 0 Countries（Public Domain）生成东亚可视范围内的域外现代陆地背景。中国本土不重复绘制现代国界，仍由历史州郡和周边族群研究层表达。
- `base-layer.js` 只在“素色地形”启用世界背景层；地形图和现代地图继续使用在线瓦片，避免重复叠加现代国家边界。世界背景永远压在历史州郡层之下。
- 取消启动时自动恢复确认框；自动缓存、最近快照和“工程 → 从本地缓存恢复”继续保留。清除旧会话标记逻辑，避免重复弹窗。
- 项目版、地图 srcdoc、便携导出和验证脚本同步新增数据与样式。
- 周边族群仍按 `vectorKind: activity-zone`、`status: 推定` 表达活动区，不把活动范围改写为汉魏吴晋行政国界；恢复浅色实线边界、低饱和填色和无底框标签，以贴近参考图。

## 史实边界

- 域外现代国界只属于素色底图可读性增强，不用于推断 184—316 年历史政权边界。
- 西域诸国、匈奴、羌、氐、鲜卑、乌桓、夫余、高句丽和南中诸部仍为研究示意活动区；乌桓显示至 207 年，其余时期沿用已有数据边界。
- 189 年少帝、献帝之际中央百官和州郡长吏名录仍以 V30 的来源与“推定／存疑／待考”状态为准，本轮未把考据名录提升为确定实授。

## 验收

- `verify-project.mjs` 新增素色世界背景、便携版边界样式和资源存在性断言。
- 浏览器回归需确认：启动不再出现恢复弹窗；素色地形显示域外陆地与国名；切换地形图／现代地图时不重复叠加；研究示意与行政层的少数民族图层规则仍有效。
