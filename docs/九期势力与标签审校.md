# 十期势力与标签审校（文件名沿用）

审校日期：2026-08-01

## 审校结论

本轮逐期检查 184、190、200、208、220、228、263、264、266、280 年地图的州域映射、势力可见性、显示名称与标签位置。

1. 190 年把“关东诸侯”画成覆盖多数关东州域的统一领土政权，超出了讨董联盟的实际组织程度。
2. 190 年益州势力沿用通用标签“刘璋”，但当时益州牧为刘焉。
3. 208 年采用战后概括，既遗漏刘表当年去世、刘琮降曹的过渡，又容易把刘备提前画成已稳定占有荆南四郡。
4. 220 年前直接过滤后置郡造成几何空白，且江夏、庐江、汉中等跨后期国界郡存在州属错位。
5. 263 年被压缩为灭汉后的魏、吴格局，遗漏汉在该年大部分时间仍存在以及巴郡、巴西等郡色。

## 190 年处理

《后汉书·袁绍列传》记州郡蜂起、桥瑁移书州郡，并列冀州韩馥对袁绍军粮的控制，可证明讨董诸军是各自起兵、推袁绍为盟主的联合行动，而非一个统一疆域国家。地图因此：

- 冀州及所属郡统一用韩馥色，州域中央直接标“韩馥”；
- 颍川、河内、陈留、东郡、济北、广陵、山阳分别按孔伷、王匡、张邈、桥瑁、鲍信、张超、袁遗着色；
- 金城、汉阳分别按韩遂、马腾着色；
- 袁绍、袁术、孙坚等不宜覆盖完整郡域者使用无底框文字定位，不再使用遮挡边界的大方框。

## 208 年处理

《三国志·吴主传》明确连叙刘表死、刘琮降曹、刘备进住夏口、诸葛亮赴孙权、周瑜程普与刘备赤壁破曹。《三国志·先主传》和关羽传相关记载又表明，刘备在败走后抵达夏口，收江南诸郡发生在赤壁胜利以后。因此十期中的 208 年节点改为年度变局图：

- 荆州北部显示曹操主要控制；
- 荆州南部以“荆州刘氏”表现刘表旧部至刘琮降曹之间的过渡，不声称刘表在赤壁时仍在世；
- 刘备使用夏口—樊口虚线军势范围，不提前涂成已占有荆南四郡的稳定疆域；
- 孙权江东州域完整保留，并增加赤壁联军注记。

## 视觉规则

- 每州使用稳定的低饱和底色，政权色提高混合权重，使控制范围首先可辨，州属差异仍可识别。
- 州名使用固定字号、浅纸色底签和细边框，不再因与势力名相交而被自动隐藏。
- 势力名锚点由所属多边形的面积加权几何重心计算，不再使用固定手工坐标。
- 地图缩放时势力名字号保持不变，地理锚点随版图正常移动。
- 虚线范围表示军势、集结区或过渡影响范围，不等同于行政边界或稳定国界。
