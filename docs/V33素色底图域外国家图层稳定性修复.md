# V33 素色底图域外国家图层稳定性修复

检查日期：2026-08-09

## 问题定位

- WorkBuddy 原静态地址 `q71T7ZIe9O6xmZrTj3ldoy/1` 当前已返回 404，不能继续作为地图资源兜底。
- 本地项目虽然已经生成 `GEO_WORLD_CONTEXT`，但国家轮廓与州郡、海岸线共用 Leaflet `overlayPane`，依靠 `bringToBack()` 调整同一 SVG 内的 DOM 顺序。时期切换和行政层重绘后，这种顺序容易改变，造成域外国家轮廓看似消失。
- V32 生成脚本只保留 15 个东亚国家，当前地图缩小到最小级别时，西侧和南侧的其他可视国家没有轮廓数据。

## 修复

- 新增独立 `world-context` pane，层级固定为 350：高于纸色瓦片和古韵滤镜，低于历史行政层；移除世界背景对 `bringToBack()` 的依赖。
- 将域外轮廓生成范围扩大到 `76—146°E、4—56°N`，保留视窗内 23 个现代国家轮廓；中国本土仍不重复绘制现代国界，由历史州郡层表达。
- 补入尼泊尔等此前被 `keep` 集合遗漏的轮廓。未配置历史名称的新增国家只绘制低饱和背景轮廓，不添加现代国名标签，避免把现代国界误读为汉末历史政区。
- 地图脚本查询参数由 `v=33` 提升为 `v=34`，避免站点或浏览器继续使用旧缓存。

## 史实边界

域外国家轮廓只用于素色底图的空间参照。它们不是 184—316 年历史政权边界，也不改变州郡、周边族群活动区和时期势力快照的数据含义。

## 验收

- `verify-project.mjs` 检查独立 pane、23 国域外数据和版本同步。
- 浏览器回归检查默认素色地形、地形图／现代地图切换、返回素色地形、时期切换及历史图层重绘后域外轮廓仍存在。
