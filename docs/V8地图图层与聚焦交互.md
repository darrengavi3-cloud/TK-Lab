# V8 地图图层与聚焦交互

## 本轮目标

V8 不改动十期历史快照、夷洲常驻层和 V7 证据索引，重点解决形势图中“行政边界、政权归属、军势示意”混在一起，以及地图内容过多时不易查阅的问题。

## 图层语义

- 国家／势力归属：州级多边形的主色，表达本期政治控制归属。
- 州级行政色：在势力主色上叠加州别色，保持同一国家内部仍能辨识不同州。
- 郡级淡色层：用低透明度和较细边线表现郡界，不与州界争夺视觉重点。
- 军势／争议范围：研究示意层中的虚线影响圈与年度军势注记，不视为稳定行政疆域。

## 显示模式

- 研究示意：保留年度军势注记、影响范围和边界通道，适合观察形势变化。
- 行政层：隐藏研究示意注记，并关闭边界通道，仅保留国家/州/郡行政表达；战役、城池和水系仍可由独立图层控制。

## 聚焦与高亮

- 点击图例中的国家/势力按钮，可隔离该势力的州郡色层；再次点击同一势力返回全局。
- “按州聚焦”按当前时期加载的州界生成选项，州郡层会同步收敛到对应州。
- “清除聚焦”恢复全部势力和全部州。
- 点击州或郡后保持选中边界高亮；切换时期或关闭父页面联动卡片时会清理旧高亮，避免样式残留。

## 标签与面板

- 国家名称按当前时期实际控制的多边形面积重新计算中心，字号固定，地图缩放只改变锚点位置。
- 州名、郡名继续按地图缩放和碰撞避让显示；高倍缩放时郡名略微放大，低倍缩放时降低密度。
- 左侧图层面板和右侧详情面板保留原有收起/展开能力，新控件随侧栏一起收起，不改变画布缩放行为。

## 验证结果

已通过项目几何、历史数据模型、统一研究模型和项目整体验证；并在本地 HTTP 回归中实际切换研究示意/行政层、势力聚焦、州聚焦、清除聚焦及 208 年时期。V8 仍将地图几何视为“考据示意”，州郡数量和边界的史实判断继续以 V7 证据快照与来源审计为准。
