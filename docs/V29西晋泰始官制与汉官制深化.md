# V29 西晋泰始官制与汉官制深化

检查日期：2026-08-04

## 西晋官制树

依据《晋书》卷二十四·职官志与卷三·武帝纪，将西晋官制树由骨架扩充为十类中央官制：

- 诸公：太宰、太傅、太保、太尉、司徒、司空、大司马、大将军（八公）及非常设的丞相／相国；逐项填入泰始元年八公任职与沿革（司马孚、郑冲、王祥、何曾、司马望、荀顗、石苞、陈骞等）。
- 列卿：九卿、将作大匠、太后三卿、大长秋。
- 大夫：特进、左右光禄大夫（金紫）、光禄大夫（银章青绶）。
- 尚书台：尚书令、仆射、左右丞、列曹尚书（泰始六曹／太康六曹，纠正原“祠部尚书”错置）、尚书郎三十五曹。
- 中书台：中书监令、中书侍郎、中书舍人、秘书监、著作郎。
- 御史台：御史中丞、治书侍御史、侍御史、殿中侍御史、符节御史。
- 常伯：侍中、给事黄门侍郎、散骑常侍、通直散骑常侍、员外散骑常侍、散骑侍郎、给事中、奉朝请。
- 将军：骠骑、车骑、卫将军，四征四镇四安四平，领军（中领军）、护军、左右卫、骁骑游击、四军、五校、四中郎将，并保留“都督职任（见州镇录）”。
- 太子官属：太子太傅少傅（泰始三年建官）、詹事（咸宁元年置）、中庶子、中舍人、庶子、舍人、洗马、率更令、家令、仆、左右卫率。
- 诸王官属：傅／友／文学、郎中令、中尉、大农、国相／内史、常侍侍郎、典书典祠典卫学官令、治书中大夫舍人。

晋官品按《通典》卷三十七晋官品（泰始官品令系统）落实到节点 `rank9`，官品体系弹窗标题同步标注“卷三十七晋泰始官品”；跨势力树形对比扩为魏·汉·吴·晋四栏。

## 季汉官制补充

继续按《三国志》纪传补充，坚持汉不实行九品中正、只保留汉代秩俸：

- 诸公：丞相（诸葛亮 221—234）、大司马（蒋琬 239—246）、大将军（蒋琬、费祎、姜维）补全历任与沿革；
- 尚书台：尚书令补法正、刘巴、蒋琬、费祎、董允、陈祗、董厥历任；
- 大夫：光禄大夫（来敏）、中散大夫（谯周、李譔）、谏议大夫（杜琼）；
- 常伯：侍中（郭攸之、费祎、董允、陈祗）、黄门侍郎（费祎、董允）；
- 将军：中领军（向宠）、中护军（费祎）、右监军（姜维）；
- 太子官属：太子仆、家令（谯周）、庶子（费祎、李譔）、舍人、洗马（费祎、董允）；
- 大夫、常伯、尚书台、太子官属改挂势力根节点，不再误挂在丞相下，消除“子节点晚于父节点存续”误报。
