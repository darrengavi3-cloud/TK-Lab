# V11 地图行政归并与周边图层

检查日期：2026-08-02

## 本轮处理

1. 184、189、190、200、208 年的郡级快照继续采用“后置郡归回母郡”的沿革规则；在此基础上，对归回同一母郡的相邻几何做共享边溶解，避免底稿分割线继续伪装成早期行政边界。无法闭合的复杂环会保留原几何，优先保证地图不留白。
2. 十一期时间轴改为 11 列，汉、三国、晋三个朝代段和全部时期卡片各自保持单行；窄屏通过横向滚动保留完整时期，不再把晋段或 280 年卡片挤到第二行。
3. 184 年黄巾影响范围新增三块低透明度斜线区域，与张角、黄巾军、波才的人物注记分开表达；黄巾仍不是稳定领土政权。
4. 夷洲常驻轮廓改为台湾本岛的简化 WGS84 海岸线，保留北岬、东岸、南端和西岸形态；它仍是地图研究标注，不把 230 年吴军远航误写成吴的行政州域。
5. 新增“周边族群范围”研究图层，显示西域诸国、匈奴、羌、氐、鲜卑、乌桓、夫余、高句丽、南中诸部。图面只显示名称和低饱和活动范围，不弹出解释性注释；图层可从左侧面板关闭。

## 史实边界

东汉十三州与 194 年河西雍州的时间分界沿用本项目既有审校：184、189、190 年不画常设雍州，200 年只把武威、张掖、酒泉、敦煌绘入河西雍州。早期郡界是以后期几何反向归并的研究复原，不等同于现代 GIS 测量。

周边族群色块表示活动范围或政治影响范围，不等同于稳定国界；鲜卑、乌桓、羌、氐等范围随时期、部落联盟和史料口径变化，后续如要做逐年边界，应单独建立年度证据表。
