# V13 人物志 · 自动保存恢复 · 数据审计中心

## 本轮交付

1. 新增“人物志”主模块（职官谱、人物志、州镇录、形势图四模块）。
   - 自动汇总职官谱任官、爵位受爵、州镇录职任中的同一人物全部履历，形成按年份排序的履历链。
   - 支持按人物、字号、籍贯、官职、辖区、史料关键词检索，按势力、记录类别、是否有立绘筛选。
   - 人物档案新增字、籍贯、生卒年、简介与立绘字段，随工程 JSON、多存档与本地缓存一起保存。
   - 履历条目可一键跳回对应官职树节点或州镇录记录。
2. 自动保存与崩溃恢复。
   - 编辑后 1.6 秒防抖自动缓存、30 秒周期缓存、关闭页面时保存保持不变。
   - 每次自动保存前保留上一版作为“最近自动快照”，可从工程菜单单独回滚。
   - 再次打开页面时，若检测到未确认的本地缓存，会提示“恢复缓存／忽略”，不再静默丢失编辑内容。
   - 手动保存或恢复后会记录确认标记，避免重复打扰。
3. 数据审计中心（顶栏盾牌按钮）。
   - 覆盖职官谱：同名官职／爵位、沿革时间倒置、遥领缺辖区、沿革年代待补、别称与正式名重复。
   - 覆盖州镇录：任期倒置、辖区待补、史料出处待补、同期任职重叠、官制树未见对应官名。
   - 覆盖人物志：有履历但缺立绘的人物。
   - 问题分“错误／待核／可选”三级，支持按模块筛选、一键定位到对应数据，并导出 Markdown 审计报告。
4. 主模块支持 URL 锚点直达：`#offices`、`#people`、`#fangzhen`、`#map`。

## 数据边界

人物志只聚合已存在于职官谱、爵位体系与州镇录中的真实任职数据；单独编辑的字号、籍贯、生卒与立绘存放在工程 `personMeta` 字段，不改变原有节点数据结构。旧版 JSON 无此字段时自动按空档案迁移。

## 验收

- 打开 `index.html#people` 可见人物卡片、统计卡与筛选条，全部现有任职人物可检索。
- 编辑人物档案后重新打开页面（或载入多存档）字段不丢失。
- 运行数据审计可生成问题清单，点击“定位”可跳转到对应官职节点、州镇记录或人物履历。
