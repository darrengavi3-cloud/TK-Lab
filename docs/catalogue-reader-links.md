# 任官閱讀關聯：第二次交付

在後台保存一條任官，由發布中心把同一修訂同步到人物履歷、官職任職者及州鎮表。資料內容的審定、工作修訂、閱讀發布及網站程式部署仍分開記錄，不提升 V86／R1。

## 操作

1. 在任官表單填寫人物、原始官名、任職性質、政權、轄區、年代及引用史料。
2. 「閱讀關聯 → 官職任職者」選擇政權和官署層級中的確切位置，可多選以登記兼領。官名、來源官職 ID 與顯示位置分開；不憑同名自動合併。
3. 需要州鎮閱讀條目時勾選「同步到州鎮表」。可選同一人物的既有條目，或留空新增。選定原條目後，本任官接管該條目的官名、任期、引文及狀態；既有網址 ID 保留。
4. 指定州鎮檔案與職任類型。行政單元可留空；選擇時須與政權及轄區一致。只有確定實任區間完整落入一段已核治所分期，才附上治所。
5. 保存修訂，重新核對已核內容，再建立候選，核對三處閱讀效果後統一發布。解除關聯會恢復原州鎮投影；如果原條目應停止公開，保留關聯並把任官設為排除或後台可見。

## 規則與責任

| 範圍 | 當前權威 | 發布政策 |
| --- | --- | --- |
| 已關聯的任官事實 | D1 任官不可變修訂 | 人物履歷與官職任職者維持已核門檻；州鎮可顯示明確標記的待核候選 |
| 官職顯示位置 | `domain/reader-references.json` 明確的政權、節點及層級路徑 | 1,459 個既有位置；建置核驗節點 ID 與名稱，結構變動須顯式遷移 |
| 既有三個官職的 11 條歷任關聯 | 同一參考登錄檔中的凍結映射 | 沿用既有已審關聯；編輯後可明確調整，不再按文字或引文內容重新猜測 |
| 未接管的 523 條州鎮基線 | atlas V86 | 保留原條目、順序、已核／待審範圍；首次原樣發布逐條比對 |
| 行政單元與治所分期 | atlas 已核登錄檔 | 只作明確引用；不新造疆界，不修改 16 個地圖分期或幾何 |
| 官職制度沿革與其他歷史領域 | atlas | 任官關聯不代表制度資料本身已搬到後台 |

同一州鎮条目只可由一條任官接管。整批保存前驗證所有引用；D1 唯一約束在併發提交時仍攔截重複，失敗不留下部分事實。未拜、未受命、追贈、未知或推定年代、不完整起迄年，都不進入確定在任快照。

引用沿用任官固定的史料修訂。改動史料原文不會悄悄改写已发布引文；須更新任官引用並重新發布。新投影採欄位允許清單，不攜帶後台審定理由。撤回已接管任官時，刪除其三處投影及重複生平事件；原有官職姓名替換範圍保留，避免舊快取文字重新冒出。

## 相容、備份與驗證

`readerLinks` 是任官可選欄位，舊修訂與 V86 遷移包不重寫。新增 `0002_bent_silver_sable.sql` 只建立州鎮接管唯一約束表，保留已部署結構、工作資料與 owner 設定。

發布清單增加職官歷任、州鎮兩組 JSON／JS，並納入摘要；仍支援第一期已發布的 readerContract 1 快照。新候選固定程式與資產摘要，程式更新後必須重建候選。備份升為 `guanshitai-backup-3`，還原工具同時核驗原版 v2 備份；不覆寫既有還原目錄。

回歸包括：原 4,336 筆遷移、523 條州鎮逐條不變、11 條歷任事實及引文一致；單次修訂三處同源、未知／未拜排除在任、撤回不復活、跨政權／人物／行政單元拒絕、併發接管完整回滾及備份相容。實際驗收與部署結果另記獨立回執。

下一步仍是逐域迁移官職制度、州鎮未關聯記錄與其他領域，補上全域身份合併及影響預覽，逐步拆分閱讀頁。此交付不宣稱全项目六階段重構已完成。
