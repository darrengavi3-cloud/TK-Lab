# Licensing and reuse boundaries

TK-Lab contains several different classes of material. A single repository-wide license would incorrectly imply that every historical text, image, map, dataset, font, or third-party reference can be redistributed under the same terms.

## 1. Original source code

Original software source code, build scripts, tests, and code-oriented configuration authored for TK-Lab are licensed under the [MIT License](LICENSE), unless a file or directory contains a more specific notice.

The MIT license is intended to make the reusable research-engineering layer straightforward to inspect, adapt, and contribute to.

## 2. Research data and editorial content

Historical facts themselves are not claimed as proprietary facts. However, curated datasets, editorial wording, transcriptions, annotations, translations, selections, database arrangements, and research notes may have separate copyright, database-right, contractual, or source-specific restrictions.

**Research data and editorial material are not automatically relicensed under MIT merely because they are stored in this repository.**

Where a dataset is later cleared for a separate open-data license, that license should be declared explicitly in that dataset's directory or metadata. A future goal is to identify auditable, originally created research datasets that can be released under a standard open-data/content license without affecting source restrictions.

## 3. Historical sources and quotations

Classical texts, modern editions, scans, quotations, transcriptions, annotations, and bibliographic material may come from sources with different legal and scholarly conditions. Source attribution in the repository is evidence metadata; it is not a representation that the underlying source is freely redistributable.

Do not assume that a quoted or referenced source may be republished in full.

## 4. Images, portraits, fonts, maps, and media

Images, portraits, fonts, cartographic data, geographical geometry, scans, and other media are excluded from the MIT code license unless their own file, metadata record, or directory notice expressly states otherwise.

Third-party material remains under its original license and attribution requirements. Material with no verified redistribution permission must not be treated as open content.

## 5. Generated artifacts

Generated bundles, deployment artifacts, exported reader data, and derived files may combine inputs with different rights. Their presence in Git does not create a new blanket license over those inputs.

## 6. Contributions

By contributing original source code to this repository, contributors agree that their code contribution may be distributed under the MIT License. Non-code contributions must only include material the contributor has the right to submit and should preserve relevant provenance and licensing metadata.

If a licensing boundary is unclear, treat the material as **not cleared for redistribution** until the provenance is reviewed.
