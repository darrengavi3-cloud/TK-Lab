# 观史台服饰资料检索与接入建议

核查日期：2026-10-04。范围：为汉末、三国、魏晋人物立绘寻找服饰资料、图像线索与工作方法。本文是资料评估和修订建议；未安装第三方 skill、未导入外部图库，也未据此宣称人物服饰已经完成严格复原。

## 检索结论

GitHub 上找到了可参考的服饰分类、研究原型和提示词 skill，尚未找到同时具备细密汉魏晋断代、逐图实物出处和明确可复用图像授权的完整图库。建议以博物馆和考古研究作为服饰依据，用开源项目组织资料和审查过程。

## 图像与专门著作

### 优先图像线索

1. [中国国家博物馆：中国古代服饰文化](https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/)：有秦汉、魏晋南北朝分期，实物、线图和历代复原人像。冠服体现身份与品阶，不能仅按“文官/武将”随意分配。网页中唐代戴进贤冠三彩俑不能不加说明直接用于三国冠式复原。
2. [中国丝绸博物馆：汉魏印象——汉晋南北朝服饰艺术展](https://www.chinasilkmuseum.com/yz/info_18.aspx?itemid=30762)：可查看对鸟对兽“宜王”锦袍（东汉晚期—晋）、汉代云气立鸟纹锦等。展览跨度较大，西汉和北朝展品不自动代表三国人物衣着；锦袍也不证明具体人物曾穿同一纹样。
3. 馆方图片权利需独立于研究用途记录。[中国丝绸博物馆版权声明](https://www.chinasilkmuseum.com/flsm/index_39.aspx)要求出处、未经许可不得修改，并对商业使用另有要求。当前采取外链和原创资料摘要，不打包馆方原图。

## 观史台接入方案

### 第一步：为重制立绘增加服饰依据卡

每个人先确定表现的生平阶段和场合，再记录服饰。基础字段：人物稳定 ID、表现年龄及选择依据、时间区间、地域、身份、场合、冠/巾、领襟、袖型、衣裳结构、腰带、履、材质、纹样。每个可见细节分别附来源、证据类型、适用年代、可信程度和待考说明。

图像权利单独记录：仅外链、许可待核、允许特定范围复用，不能把代码 MIT 许可理解为所引古籍或照片也可任意复用。保留“不详”，不自动补成精确事实。

### 第二步：将证据转换为绘制约束

- 文士、朝臣、武人、皇族、女性与少年分别选择适合的日常/朝会/军旅场合。相同阵营的视觉配色属于项目设计，不宣称历史统一制服。
- 明确单人 9:16 独立构图，面部和双肩正对观者，年龄适宜，冠与双手完整。150 张早期立绘按独立重制验收，原裁切或拼图不能作为完成稿。
- 每张只使用少量已查证或明确标为设计推断的可见特征。避免无依据的巨型金冠、统一兽面肩甲、错时代纹章和装饰堆叠。
- 区分“依据文物设计的项目插画”与“严格服饰复原”。即便服饰有依据，人物容貌也不能因此标为真实肖像。

### 第三步：生成后按项复核

先验正脸、年龄、单人构图和完整边缘，再复核领襟、首服、结构与时间/场合一致性。规则只提示疑点，最终要对照证据并留人工审查记录。不要用模型自评分充当服饰准确率。

### 第四步：让资料成为可阅读内容

建议在人像详情中提供“服饰依据”入口：点击冠、袖、腰带等对应区域，解释采用的形制、依据文物和未确定之处；资料页按时间、身份与场合筛选。用户会因此理解社会身份和制度变化，而不仅是看到更多纹样。

本轮已完成检索、出处与使用边界记录，并把保守服饰约束传入正在进行的立绘工作。新的资料入口和整套人物服饰逐项考证仍属修订建议，未冒充已经上线。
