# 全站正面立绘修订

用户已确认范围包括原有500张及新增100张。严格正面指头部、肩部和躯干朝向画面，双眼直视，鼻梁居中；三分之四侧脸或转肩不算通过。

追加要求：早期由GPT大图裁剪的立绘需要重制。已核到16项明确参考裁切和1项仍为多人拼图；另133项早期资产缺少清晰的逐人生成来源记录，保守纳入独立重制，共150项。这不表示150项全部已经证实来自裁剪。具体稳定人物与资源ID见independent-redraw-plan.json。

这150项每人单独生成一张9:16正面站姿原图，冠饰与双手完整，画面至膝下或全身，避免多人拼图与沿用旧裁剪边界。此前仅修正朝向的早期试稿保留为历史候选，不计最终验收。其余350项继续逐人修订朝向与年龄。全站总目标仍为600项，不增加或重复人物绑定。

原有资源的portraitId与personId保持不变。修改后的显示图作为新资源保存，原图用于追溯，Figma旧设计引用仍指向旧资产，新的生成图不伪造Figma节点。新增100人按稳定personId登记，不通过同名自动合并。

绘制年龄是艺术表现的生涯阶段，不属于新增史实生年/卒年。已知青年人物不使用老年化须发与皱纹；旧图修订保留人物脸型、服饰、配色与风格，并核对明显不适龄表现。

生成进度与原图逐批保存在codex/frontal-portraits-20261004分支；生产尚未完成时不替换已发布站点。全量完成并视觉验收后，生产清单进入构建。原有500项身份绑定冻结边界保持原样，新增100项通过显式记录扩展边界。
