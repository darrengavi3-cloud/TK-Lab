# 观史台交互契约（V64）

## 检索与导航

- 全站统一使用一个“检索”入口，支持 `Ctrl/Cmd+K`；模块页通过范围按钮打开统一检索，不再维护平行的模块检索输入框。
- 检索支持范围芯片、`@人物`、`#战事`、`官:`、`地:`、`水:` 和年份语法；结果按模块分组并按稳定 ID 去重。
- 检索输入必须 IME 安全；非组合输入的 Enter 才打开结果，清空按钮立即清除内容并恢复焦点。
- 页面内筛选改变后，人物分页回到第一页；详情抽屉关闭后焦点回到触发人物卡或按钮。
- 人物档案与时期快照是两个互斥视图，不通过同一列表混排；快照条目点击进入对应人物履历或官署定位。

## 证据与状态

- 确定、推定、存疑、待考始终有文字标记；不能只用色彩表达。
- 立绘、制度名号和任官记录的来源层分开。没有图像资产时使用带人脸的界面识别设计，不写成“史实画像”。
- 未核定官品或跨政权沿用名号不得在排序中静默合并；显示层以稳定 `sortOrder` 保证可复核。
- 朝堂序位使用 `data/office-order-policies.js` 的显示政策；优先读取 `courtOrder`、`generalTitleSortOrder` 和 `sortOrder`，同品无证据时按并列层级显示。
- “其他”类别不作为朝堂可见官署；原始记录保留在规范源和审校入口，地方官按地方层显示。
- 人物卡头像只渲染 `status=ready` 的有人脸资源；`designOnly` 和 `fallback` 以文字状态呈现，不展示无五官图片。
- 人物统计使用单行紧凑带，宽屏不因指标数量产生孤立的第二行卡片。

## V51 视觉与立绘状态

- 人物记页面不显示设计板、生产数量或版本残余状态行；资源状态保留在后台清单和审计数据中。
- 人物卡头像必须来自已登记的 `status=ready` 资源；无资源时不得渲染无五官占位图。
- 全站共享史料工作台视觉令牌，模块不得自行引入外部字体或网络样式依赖。

## 响应式与无障碍

- 重要触控目标不小于约 44px；键盘焦点清晰可见。
- 760px 以下人物双按钮转为横向，名号卡片改单列，详情内容自然滚动，不创建第二个页面滚动容器。
- 支持 `prefers-reduced-motion`；卡片上移效果不得影响信息读取。

## V54 主题与动效

- 主题由 `data-sgz-theme` 控制，默认“兰台清昼”，可切换“朱批纸本”“青灯夜校”。主题只改变语义令牌，不改变政权色或史料数据。
- 动效由 `data-sgz-motion` 控制；标准动效仅用于模块切换、抽屉进入和结果状态变化，减少动效时使用短淡入或直接切换。
- 主题、密度和动效偏好使用独立的小型 `localStorage` 记录；工程数据仍由现有 IndexedDB 缓存负责。

## V55 阅读／审校模式

- 默认进入阅读模式，只呈现读者摘要、必要元数据和明确证据状态；原始记录与来源定位仍保留在数据对象中。
- 审校模式显式显示编辑、来源定位、任期冲突、缺失释文和待考数量。切换模式不改写项目数据。
- 缺少精确府署定义时显示“府署未建档”；不得用通用府署或丞相府作为任意官位的点击兜底。

## V55 稳定身份与检索

- 人物合并只能依据规范 `personId`。姓名、异体、表字和括号内容只能作为显式身份解析或检索键。
- 同名异人必须分配不同 ID；人物卡以 ID 为键，每个 ID 只出现一次。旧 ID 仅通过登记的兼容映射迁移。
- 空检索显示最近使用、常用入口和审校任务，不预先渲染全库。非空结果显示命中原因，并以模块加稳定 ID 去重。
- 表字、立绘、人物详情和跨模块跳转优先按人物 ID 关联；姓名回退只服务旧数据兼容，不产生新合并。

## V55 六版块交互

- 职官谱：官位点击只选中官位；人物点击进入履历；“府”按钮只进入与该官位、时期和府主匹配的精确府署。
- 战事纪：默认按年代，另有按交战方和按战役链；州名不是主要分类入口。
- 州镇表：职任表、某年快照和两年对比互斥；重叠任期只在审校模式提示。
- 食货志：146／157 基线与 168—316 主体分开；只有可比的确定年份数值进入比例图。
- 金石录：列表字段与源文表头一一对应；详情显示完整释文或明确的缺载状态。
- 形势图：V55 不改变地图本身，只保证战事和州镇的既有定位动作不回归。

## V56 导航与证据案卷

- 桌面模块切换的唯一所有者是左侧卷脊导航；顶部不再维护第二套模块标签。移动端固定显示“职官、人物、战事、形势、全部”。
- 上下文栏是模块常用筛选的唯一所有者。页面内容区仅保留高级筛选、时间对比或审校动作，不重复政权、类别和检索入口。
- `Ctrl/Cmd+K` 打开全局检索；“检索本页”只改变范围。IME 组合期间不执行 Enter，关闭后焦点回到原触发控件。
- 桌面记录选择更新右侧证据案卷，不强制弹出抽屉；980px 以下记录详情使用全宽抽屉，并在关闭后恢复焦点。
- 人物名录的每一行都是可聚焦按钮，以 `personId` 为键。详情时间线只显示该 ID 的全部任官、受爵、州镇和时期录，不按姓名重复建卡。
- 官位卡点击只选择官位；只有显式“府”按钮或证据案卷中的“进入对应府署”动作可进入 `residenceDefinitionFor(当前官位)` 返回的精确府署。
- 战事、州镇、金石和食货的行选择均更新同一证据案卷；地图定位、人物履历等跨模块动作保留稳定 ID 或记录 ID。
- 证据状态由符号、文字和导轨共同表达：确定／推定、待考、争议不能只依赖颜色。

## V56 响应式与偏好

- 1280×720 顶栏不得换行，主要记录应在顶栏下约 160px 内出现；人物桌面首屏至少可见七条名录记录。
- 390×844 不得横向溢出；证据栏隐藏，人物和金石的中栏详情改由全屏抽屉承载。
- `uiPreferencesV56` 对应存储键为 `sgz_ui_preferences_v56`，只含 `theme`、`workspaceMode`、`navigationCollapsed`、`evidenceCollapsed`。
- 支持 200% 缩放和 `prefers-reduced-motion`；减少动效时所有 V56 过渡缩短为近即时切换。

## V57 统一检索与状态边界

- 全局检索是唯一读者检索入口，顶栏显示“检索＋⌘K”；模块内不得出现“检索本页”或重复文本输入框。命令面板仍可按模块范围收窄。
- 外观设置使用锚定浮层，不打开第二层页面；主题、密度和动效偏好继续写入独立的小型 UI 存储。
- 阅读模式只显示 `evidenceStatus` 与有依据的“待考”；`reviewState`、审校任务和内部审计状态只在审校模式显示。
- 每个可见人物必须有明确史料实体与有效关系；人物只按稳定 `personId` 出现一次。表字只有在正史正文、裴注或《晋书》等明确出处中才显示。
- 职官谱只允许朝堂与表格两种前台视图，官位选择必须绑定所选官位；金石档案层级仅保留在内部数据与导出，食货志三个视图互斥。

## V62 人物检索、纯净题名与金石阅读

- 人物记保留一个常驻检索框，支持姓名、简繁异体、别名、表字、官职、爵号、封地和历史归属；姓名精确匹配优先，其次为别名／表字、官职／爵号和归属。
- 常驻检索必须兼容中文输入法组合输入、清空按钮、上下键和 Enter；清空后回到当前人物数据集的完整名录。
- 人物主标签只能是后汉、魏、季汉、吴、西晋，跨朝人物也按该顺序排列。无法确认的标签不在读者态猜测显示。
- 读者标题不得出现项目生成的说明性括号或前置 `【额】` 标记；原始题名、史料正文、书名和来源定位不受此规则影响。
- 金石正文只以转义文本片段进行检索高亮；不得使用原始 HTML 指令或字符串注入方式渲染释文。
- 390px 下筛选栏可折叠，人物与金石详情使用全宽抽屉；200% 缩放和减少动效模式必须保留焦点、滚动位置与可见关闭动作。

## V63 发布门禁与安全渲染

- 人物姓名可作为目录实体显示；表字、籍贯、生卒、任官和封爵分别消费 `publicationStatus`。阅读态只显示 `verified` 字段，未登记字段默认隐藏；审校态保留完整候选资料。
- 阅读构建只消费读者投影；人物注册表、工作簿行号、检索日志和本机路径不得进入读者首屏或公开数据包。
- 检索命中、食货图表、地图详情和错误页只创建文本节点或安全 SVG 属性。数据中的标签字符串一律按文字显示，不作为可执行标记解释。
- 阅读态不为隐藏的证据案卷保留网格宽度；审校态展开、收起证据栏时不得改变当前记录或键盘焦点。

## V64 导航、检索与持久化

- 模块、筛选、页码、人物、碑刻和地图时期以稳定 ID 写入 URL；刷新、前进和后退必须恢复同一状态。页面标题随当前模块与详情更新。
- 人物检索分为直接命中与关联命中。姓名精确匹配最优先，别名／表字仍属直接命中；官职、爵号、封地和历史归属属于关联命中，并显示命中原因。
- 人物检索支持 IME、上下键和 Enter。移动“全部模块”使用真正的模态对话框，必须圈定 Tab、支持 Escape，并在关闭后把焦点还给触发按钮。
- 全局快捷键只保留 `Ctrl/Cmd+K`；保存与编辑快捷键仅在审校态及相应编辑区域生效，不覆盖浏览器查找或普通页面复制。
- 工程缓存使用脏状态与去抖保存；周期任务只检查脏状态，无变化不得创建历史快照。离开页面时仅同步提交尚未保存的变更。
- 首屏只加载壳层与持久化模块。人物、州镇、金石、SheetJS 和地图按模块或审校动作载入；地图 iframe 仅在第一次进入形势图时设置地址。

## V64 稳定前端分层

- 脚本职责固定为 `assets/app/shell.js`、`people.js`、`fangzhen.js`、`jinshi.js`、`persistence.js`；新增逻辑应进入相应模块，不再继续扩张单体入口。
- 样式只按 `tokens.css`、`base.css`、`components.css`、`modules.css`、`responsive.css` 五层加载。旧版本样式可作为迁移档案保留，但不得继续进入运行时级联。
- 交互记录必须使用原生按钮、链接或具备完整键盘语义的复合控件；人物头像统一使用延迟加载与异步解码。
- 读者人物关系由 `SGZ_V63_READER_PERSON_RELATIONS` 提供。任官索引必须与 `appointmentIds` 逐项闭合；封爵索引必须使用 `eventId@personId` 区分同一事件的多个受封者。缺少纯净关系投影时，读者态不得回退公开整个运行时关系集。
- 地图 `divIcon` 和 tooltip 如必须接收 HTML 字符串，所有数据文字必须经统一转义，颜色只接受白名单或严格 hex。`SGZ_READER_BUILD` 下的古水名界面只发布名称、别名、缩放级和几何段数，不发布审校状态、卷次、出处和证据说明。
- 撤销、重做、命名版本回滚和载入存档应各自只产生一个增量历史项；监听器抑制必须持续到 Vue `nextTick`，不得把撤销导致的变更再次记为新操作。
- 持久化核心由 `persistence-core.js` 在应用启动前同步注册，`persistence.js` 仅提供模块兼容导出。初始化必须先验证 `createDirtyState` 与 `createPatchEngine`，不得在核心加载失败后继续挂载应用。

## V66 纠错交互

- 外观按钮每次只打开一个锚定浮层；再次点击、按 Escape 或把焦点移出后关闭，关闭时焦点回到触发按钮。运行时不得加载旧主题抽屉。
- 职官谱读者标题只显示制度名称，不显示布局要求、编辑说明或“全部时期 · 官署沿革全期 · 府署”等工程文案。中书监、中书令等不同官位必须是独立可聚焦节点。
- 曹魏爵位节点与人物封爵时间线通过稳定 `peerageNodeId` 双向跳转；跳转爵位时强制进入爵位目录视图，不得落入官职表格空白态。
- 人物记只有“统一人物名录”和“时期官署”两种互斥视图。导入工作簿名、数据集类型和 `dataset=` 参数不影响读者列表；旧链接中的该参数被忽略。
- 州镇任职记录与治所字段分别发布：任职可见性继承 V65 门禁；治所尚未通过来源和年代门禁时，仅省略治所字段及占位文案，不得吞掉已经核准的任职记录。审校态仍可查看治所处置和未发布原因。
- 战事纪默认显示全部 62 条读者记录的单一编年线。三个时代按钮只滚动定位；全局密度控制行高和摘要行数，不改变列表容器高度。条目详情、地图入口分别使用原生按钮，稳定战事 ID 写入 URL 并支持刷新、前进和后退恢复。

## V66 后汉官职结构交互

- 中枢主图始终可见，专题导航只切换一个附加区块，不滚动到六个同时存在的长页面。
- 官位使用原生按钮并以 `aria-pressed` 表达选中状态；桌面点击只更新右侧详情，不夺走官位按钮焦点。
- 皇帝只承担结构定位，不伪装成没有详情的可点击官位；太子按钮进入已核 `residence:han:east-palace`，不生成新的东宫数据。
- 阅读态明确拒绝 `officePublicationStatus` 为非 `verified` 的节点；没有显式发布字段的既有基础官位继续遵循现行规范投影，审校候选不因专题分组升级。
- 760px 以下详情使用单一全屏对话框；Tab 留在详情内，Escape 或关闭按钮退出，背景导航与主图设为 inert，关闭后焦点回到触发官牌。
- 结构分组只表达阅读路径。五校尉、中郎宿卫等专题不得把现存审校中的错误父级包装为正式制度隶属。

## V67 州镇表与金石录交互契约

- 全局搜索是唯一文本搜索状态。进入州镇表或金石录后，全局搜索自动限定模块范围；模块内容区不得新增另一套搜索框、搜索历史或清空逻辑。
- 州镇表桌面行选择只更新右侧案卷和 URL，不打开抽屉；980px 以下同一选择打开全屏详情。人物履历与形势图定位是独立原生按钮，不得由整行点击隐式触发。
- 州镇左栏只列当前公开记录实际存在的辖区及动态数量。不存在公开治所分期或相关长官时，关联区整体不渲染；未核治所不生成占位文字。
- 金石目录每页十二条。点击目录项更新案卷、页码和稳定金石 ID；上一条／下一条按当前筛选后的全序列移动，并同步页码和 URL。
- 金石图像区只在至少一项已核本地媒体资产通过发布门禁时渲染。媒体缩略图切换不改变当前金石 ID；替代文字必填，图像加载失败不得留下伪资料说明。
- 金石释文只按文本节点渲染。检索高亮函数返回 `{text, hit}` 片段，模板以文本插值和 `mark` 组合展示；任何导入字符串均不得进入 HTML 指令或 `innerHTML`。
- 桌面目录、表格与详情区不嵌套第二层同向滚动；移动端抽屉圈定焦点、支持 Escape，并在关闭后恢复到触发记录。触控目标不小于四十四像素。
- URL 读取时先加载对应模块数据，再恢复筛选、页码和稳定 ID；不存在或已被门禁隐藏的 ID 回退到当前筛选首条，不产生空白工作台或初始化异常。

## V68 人物小传与州／方镇分层

- 人物详情中的“人物小传”只读取已进入读者投影的传记文本；无文本时隐藏整块，审校来源和工作簿字段不在阅读态渲染。
