# V14 战事纪板块

## 本轮交付

1. 新增“战事纪”主模块（职官谱、人物志、战事纪、州镇录、形势图五模块）。
   - 独立战事档案 `data/battle-records.js`，与地图现有战役图层共用标识与坐标，避免同一战役出现两套数据。
   - 收录 28 条编年要事（168—280 年）、14 场重大战役、9 处重要战场，合计 51 条记录。
   - 每条记录包含年份、朝代/年号、交战双方、战果、战场方位、史料出处与置信度。
2. 战事纪交互。
   - 支持按关键词检索（战役、人物、战场、史料出处），按类别（编年要事／重大战役／重要战场）与十一期地图时期筛选。
   - 点击卡片打开详情抽屉，可查看双方、战果、史料出处，并可一键跳转到对应年份的形势图。
   - 详情中列出与战事文本匹配的人物，可点击进入人物志查看履历。
3. 数据审计中心新增“战事纪”检查项：战役缺少年份、同名战役重复、战场时间范围倒置、要事缺少年份；审计结果可一键定位到对应战事详情。
4. 便携版同时内嵌战事档案：主页面战事纪模块与地图 iframe 共用同一份 `SGZ_BATTLE_RECORDS`。

## 数据边界

战事纪是历史地图战役数据的整理视图，不新增独立军事测绘；战役坐标沿用地图图层，编年要事用于串联形势图十一期时间轴。史料出处优先《后汉书》《三国志》《晋书》原典，置信度按“确定／推定／待核”区分。

## 验收

- 打开 `index.html#battle` 可见 51 条战事记录，统计卡显示 28／14／9／11。
- 点击“官渡之战”等卡片可打开详情，并可跳转到形势图对应年份。
- 数据审计中心可列出战事纪问题并定位到详情。
