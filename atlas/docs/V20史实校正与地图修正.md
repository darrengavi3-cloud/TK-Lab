# V20 史实校正 · 郡级渲染与沿革链修复

检查日期：2026-08-02

## 本轮调整

1. 189 年单独建郡级快照：
   - 南安郡为中平五年（188）分汉阳郡豲道县置，189 年少帝图保留南安郡；
   - 184 年仍不提前显示，190 年维持原有显示。
2. 199、219 年补开郡层渲染：
   - `preSanguoIds` 纳入 `jianbing`、`xiangfan`，两期恢复郡界、郡名与分郡势力着色；
   - 补 199/219 东汉郡名覆写：建宁→益州、范阳→涿郡、天水→汉阳、淮南→九江、京兆→京兆尹、冯翊→左冯翊、扶风→右扶风、河南→河南尹。
3. 219 年跨州郡块归一：
   - 汉中归益州、江夏归荆州、庐江归扬州；同一郡的魏吴底稿块按母郡州属合并，不再出现“汉中（荆州）”等重复块；
   - 南安郡建安十九年（214）已废入陇西，219 年归并陇西；220 年曹魏复置后恢复显示。
4. 沿革父级链修正：
   - 建平郡永安三年（260）分宜都郡置，父级由南郡改为宜都；
   - 上庸郡按“魏文帝合房陵、上庸等郡设新城郡，后又分其西部设上庸郡”改为先归新城郡、再上溯汉中。
5. 264 年分置梁州与广州：
   - 梁州按《华阳国志》咸熙元年（264）分益州巴、汉七郡置，264/266 均绘制梁州；
   - 广州按吴永安七年（264）分交州置，264 快照拆出交、广两州；
   - 东广汉郡咸熙初（264）省并广汉，264/266 不再显示。
6. 势力控制修正：
   - 199、200、208 年河西雍州（武威、张掖、酒泉、敦煌）不再误归曹操，改按凉州诸将着色并加注记；
   - 199/200 年扬州按魏吴分治：淮南归曹操，江东归孙策/孙权；荆州仍按刘表整州表达；
   - 199—219 年司隶保持东汉名称，220 年起才显示司州。
7. 220 年庐江块去重：安丰郡（221 置）在 220 年归并回庐江后按母郡统一归扬州，只保留魏吴两块。

## 史实依据

- 南安郡：维基百科《南安郡（东汉）》，中平五年置、建安十九年废入陇西；曹魏复置。
- 建平郡：维基百科《建平郡（东吴）》，永安三年分宜都郡置。
- 上庸郡：维基百科《上庸郡》，魏文帝合房陵、上庸等郡设新城郡，后又分其西部设上庸郡。
- 梁州：维基百科《梁州（曹魏）》主说为景元四年（264）分蜀汉故地为益、梁二州；《华阳国志·卷一》记咸熙元年平蜀后分益州巴、汉七郡置梁州。
- 东广汉省并：《华阳国志·卷三》刘氏延熙中分广汉置东广汉，咸熙初省。
- 广州：维基百科《广州（古代）》，三国时东吴分东汉交州为交、广两州。
