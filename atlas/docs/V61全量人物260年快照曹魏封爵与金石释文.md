## 范围

V61 以 V57 壳层、V59 官制和 V60 审校数据为基线，只处理人物记与金石录。形势图时期、几何、图层和稳定 ID 均不改动。

## 金石录

现有 188 条金石目录和稳定 ID 不变。V60 的 142 条空释文逐条进入中文 Wikipedia 与维基文库发现检索；检索结果只用于发现候选，必须能定位碑本、拓本、馆藏目录或正式释文才可进入规范 `inscription`。

V61 实际接入 4 条可追溯释文：

1. 《谷朗碑》：采用《全三國文》卷七十五所录碑本全文；台北故宫藏品页只用于核对碑刻身份。
2. 《天发神谶碑》：采用《全三國文》卷七十五所录残文，并用 `□` 保留阙字；补字、连读本和宋以后增刻分别保存，不进入原碑正文。故宫博物院宋拓藏品页用于拓本与身份复核。
3. 《禅国山碑》：采用《全三國文》卷七十五所录碑本残文，无法稳定转写的异体字保守记为 `□`。
4. 《受禅表》：采用《全三國文》卷二十八据碑本及《隸釋》卷十九所录残文，阙字原样保留。

采用后已有释文由 46 条增至 50 条，仍有 138 条保持空值。空值记录在阅读态不显示“待补”占位；审校态保留逐条检索 URL、命中题名、核验结论和未采用原因。
