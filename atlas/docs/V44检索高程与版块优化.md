# V44 检索命令面板、高程地形与四大版块分批优化

## 范围与原则

- 以 V43 为基线：先完成检索统一、高程叠加与四大版块优化，再全量验证并私密发布。
- 检索目标是把“全局高级检索＋各模块搜索框”收敛为一条跨模块命令面板；各模块保留常用筛选，高级筛选折叠，不改变编辑器的数据模型。
- 高程采用公开瓦片服务叠加（AWS Terrain Tiles / Esri Hillshade），不把 GitHub 仓库数据作为底图主体；CHGIS、tilezen/joerd 只更新审计记录。
- 战事纪、州镇表、食货志、金石录四项分批落地，每批单独提交与验证。

## 检索命令面板

- 顶部搜索按钮或 `Cmd/Ctrl+K` 唤起“全局检索”面板，一次覆盖职官谱、人物记、州镇表、战事纪、食货志、金石录、古水名、地图时期共 9 个范围。
- 支持方向键移动、Enter 打开、Esc 关闭；结果按模块分组显示匹配高亮，点击直接定位到对应模块与节点。
- 输入支持快捷范围写法：`@人物`、`#战事`、末尾 3–4 位数字限定年份；职官谱高级筛选（势力、类别、品秩、特殊属性、年份）收进“更多筛选”折叠区。
- 人物记工具栏新增“更多筛选”，把时代、相关年份、史料来源、证据状态、文武类别、官署类型收进折叠区；常用筛选仍保留“政权、记录类别、仅有立绘”。
- 跨模块共享 `searchState`（query、scope、chips、activeIndex），不修改原有 `searchFilters`、`peopleQuery` 等字段，不覆盖用户草稿。

## 地图高程与 GitHub 审计

- 地图新增“高程山影”底图（Terrarium，AWS S3），低缩放（<7 级）自动叠加 Esri Hillshade 兜底；切换底图不影响行政、郡名、水系、战场等矢量层。
- 新增“高程读数”开关：点击地图后从 Terrarium 瓦片解码像素并显示海拔（米），取不到时显示“高程未取到”，不显示错误值。
- `data/public-vector-audit.json` 更新：`cga-harvard/chgis.github.io`（CHGIS 门户）为权威历史行政区划参考但不含高程、数据需按官方渠道授权，结论“不导入边界”；`tilezen/joerd`（MIT）为 Terrarium 生成工具链，结论“不导入仓库数据，直接叠加公开瓦片服务”。

## 四大版块分批优化

### 战事纪

- 条目新增“地图 ›”按钮，点击跳转对应时期地图并聚焦战场地名；详情页新增“定位地图战场”与“在形势图中查看对应时期”。
- 详情页新增“前因→本项→后续”关联链，基于统一战事档案的编年与战役映射。
- 筛选维持州组、时间支线两组芯片，并补充地图跳转入口。

### 州镇表

- 每行新增 168—316 年任期时间条；有起止年用实线，起止缺失用虚线并保留 `tenureText` 原文。
- 工具栏新增“年份快照”与“对比年份”输入：年份快照显示该年任职记录，两年对比显示“新出现／不再任职”差异。

### 食货志

- 政权筛选改为芯片（全部／汉／魏／吴／晋），类别筛选保留。
- 制度条目新增证据徽标：确定、较高、推定、存疑分别着色。
- 户口表新增“相对规模”内联 SVG 迷你条形图（按户数相对太康基准缩放）；编辑功能原样保留。

### 金石录

- 新增“全部档案层级／核心／扩展／争议”芯片筛选。
- 展开行释文与释读说明支持检索词高亮；争议材料显示“释读争议”说明。
- 关联人物按逗号/顿号拆分可点击，直接打开人物履历；官职名以附属文本保留。

## 验证与发布

- 新增 `scripts/verify-v44.mjs`：命令面板快捷键与跨模块计数、芯片筛选、高程图层与海拔读数、四模块新交互、便携导出内嵌、公共地图审计与文档。
- 继续运行全部既有验证：`verify-research-model.mjs`、`verify-v42.mjs`、`verify-project.mjs`、`verify-map-data.mjs`、`verify-historical-model.mjs`、`verify-v43.mjs`、`npm test`。
- 功能分支 `codex/v44-search-elevation-modules`，验证后同步私密网站运行时子集并推送；私密 Sites 部署新版本（保留 V43 为回滚点），成功后再合并 `main`。
- 交付：私密访问链接、提交记录、GitHub 地图审计结论、V44 文档与“待考”清单。

## 假设与默认项

- 本轮检索“命令面板＋模块精简”为最终形态，不做多套主题。
- 高程采用公开瓦片服务，不引入 GitHub 仓库底图主体；CHGIS 仅记录为行政边界参考。
- 四模块全部纳入本轮，按“战事纪→州镇表→食货志→金石录”分批落地。
- 浏览器验收依赖可用浏览器；若会话不可用，将停在已推送的功能分支并明确标注待办。
