# V32 缓存启动策略与族群边界样式

检查日期：2026-08-06

## 本轮问题

- 启动恢复弹窗依赖 `beforeunload` 清除会话标记。刷新、嵌入地图 iframe 或浏览器异常退出时该事件不保证执行，旧标记会把下一次正常打开误判为异常退出。
- 单文件地图 srcdoc 中曾有一条旧 CSS 规则强制把周边族群矢量边界设为透明，导致参考图需要的浅色实线边界在便携版中消失。

## 实现

- 取消启动时自动恢复确认框；自动缓存、最近快照和“工程 → 从本地缓存恢复”继续保留。清除旧会话标记逻辑，避免重复弹窗。
- 项目版、地图 srcdoc、便携导出和验证脚本同步族群边界样式。
- 周边族群仍按 `vectorKind: activity-zone`、`status: 推定` 表达活动区，不把活动范围改写为汉魏吴晋行政国界；恢复浅色实线边界、低饱和填色和无底框标签，以贴近参考图。

## 史实边界

- 西域诸国、匈奴、羌、氐、鲜卑、乌桓、夫余、高句丽和南中诸部仍为研究示意活动区；乌桓显示至 207 年，其余时期沿用已有数据边界。
- 189 年少帝、献帝之际中央百官和州郡长吏名录仍以 V30 的来源与“推定／存疑／待考”状态为准，本轮未把考据名录提升为确定实授。

## 验收

- 浏览器回归需确认：启动不再出现恢复弹窗；研究示意与行政层的少数民族图层规则仍有效。
