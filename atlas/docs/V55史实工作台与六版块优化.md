# V55：史实工作台与六版块优化

## 范围

V55 以 V54 为基线，优化职官谱、人物记、战事纪、州镇表、食货志、金石录和统一检索。形势图的几何、时期、图层及渲染文件冻结，只验证州镇、战事等入口仍可跳转。

本轮不以条目数量作为正确性门槛。原始记录、读者摘要、证据和审校状态分别保存；缺载写明“待考”“来源待补”或“源文未见”，不自动补成确定史实。

## 数据与阅读投影

- 研究模型继续保留 `rawRecord`、`readerSummary`、`evidence`、`researchStatus` 和来源字段。阅读投影只清理展示文本，不删去证据对象。
- 页面默认进入“阅读”模式，隐藏内部定位、编辑动作和批量审校指标；切换“审校”后才显示这些内容。
- 阅读／审校、主题、密度和动效写入独立小型偏好项，不写入大型工程缓存。

## 统一检索

- 空查询不再生成全库结果，改为最近检索、六个常用入口和审校任务。
- 结果按模块分组，以稳定实体 ID 去重，并显示命中字段原因。
- 人物、官职、州镇、战事、食货、金石、水名和地图时期均从同一命令面板进入；模块页只保留带范围的入口按钮。

## 职官谱

- 朝堂官位点击只选择官位；人物点击进入人物履历；“府”按钮只在存在精确府署定义时进入府署。
- 有开府可能但尚无精确府署定义的官位显示“府署未建档”，不再落入丞相府或通用府署。
- 运行时统一补齐 `serviceDomain` 与 `institutionType`，将州府、郡府、县署、东宫、王府、丞相府、将军府等分开。
- 曹魏常伯的显式排序只作用于曹魏。季汉、孙吴、西晋按各自名号证据和排序字段展示；待考模板不冒充确定制度。

## 人物记

- `personId` 是合并人物的唯一依据；姓名、括号、别名只用于检索和显式身份解析，不再直接触发合并。
- 旧来源 ID 通过兼容映射归并到规范 ID。董允由旧 ID 映射为 `person:shu:dong-yun`，表字和立绘清单同步使用规范 ID。
- 同名异人保留不同稳定 ID；人物卡每个 ID 只出现一次。详情中的多段履历按时间、官职、辖区与出处排列。
- 表字补充表全部按人物 ID 关联；误读名称只留在实体审计数据，不作为公开别名。
- 人物分页桌面每页 48 人、移动端每页 20 人，筛选变化自动回到第一页。
- 对人物记进行桌面端全分页运行时复查：卡片由 621 条归并为 545 个稳定人物 ID，56 组跨模块重复身份已合并；唯一仍同名的是两位“李丰”，分别标明“季汉李严之子”和“曹魏中书令”，不作错误合并。逐项结论见 `data/v55-person-identity-audit.json`。

## 战事纪

- 默认按年代展示，另提供“按交战方”和“按战役链”。州名不再作为主要分类方式。
- 战事详情显示来源、证据状态和可信度；战役与地图仍可互跳。
- 12 个战场坐标档案尚无逐条史料定位，明确标为“来源待补”，不伪造出处。

## 州镇表

- 记录统一投影为行政单位、治所、人物、职任和任期；阅读表不显示籍贯与整理注释。
- 支持职任表、某年快照、两年对比和移动端档案卡。
- 同官同辖区异人任期重叠进入审校清单，不静默覆盖。

## 食货志

- 数据移至 `data/shihuo-records.js`，分为制度、经济事件和量化记录。
- 146 年与 157 年只作为战乱前基线，168—316 年为主体，不混入同一时段统计。
- 户口图只比较有确定年份且不是约数、回顾值或推算值的 4 条记录。

## 金石录

- DOCX 解析器按 Word run 识别 `w:strike`、`w:dstrike`、`w:del` 与 `w:delText`，只排除对应删除内容。
- 表头分别绑定题名、材料类型、国别、档案层级、年代、出土地、关联人物、官职、释文和说明。
- 本轮附件解析 128 条：核心 65、扩展 63；42 条有明确释文。其余 86 条显示“源文未见明确释文标识”，不自动生成释文。连同既有 60 条目录，页面共显示 188 条，其中 46 条有释文。
- 初始载入、工程导入、缓存恢复和旧模型迁移统一经过 V55 字段规范化；旧缓存缺少档案层级时按证据状态显示“核心／争议”，不再出现表头下空白错列。

## UI

- V55 采用“紧凑史料工作台”：纸灰背景、墨色正文、朱印操作、金色证据提示。
- 顶部导航压缩到 64px；工具栏、统计带、卡片、表格和抽屉使用统一边界、焦点与移动端规则。
- 三套既有主题继续使用语义令牌，不改变政权色和数据含义；减少动效设置继续生效。

## 验证边界

`scripts/verify-v55.mjs` 检查数据投影、人物 ID、表字、立绘、府署入口、官职分类、检索、战事视图、州镇视图、食货基线、金石删除线、V55 样式、便携资源和形势图冻结哈希。所有既有验证也必须继续通过。

提交、推送、私密镜像同步和 Sites 部署不在本轮授权范围内；完成状态只记录本地规范源、运行时、便携版与浏览器验收。
