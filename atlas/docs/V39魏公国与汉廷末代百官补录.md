# V39 魏公国与汉廷末代百官补录

## 范围

- 建安十八年（213）魏公国肇建：分列魏公国官署与汉廷残余官署。
- 延康元年（220）曹丕受禅前：保留具名官员，同时登记九卿中“人名未详”的官职。
- 对应人物写入人物记；有明确史传者补生平，材料仅见一职者不擅补生卒与后续履历。
- 新增八幅项目生成头像，统一裁切为 `82×120`；`portraitKind: 'ai-illustration'` 明确其为非史实肖像。

## 证据层级

主要依据为《三国志·武帝纪》《三国志·文帝纪》《三国志·华歆传》《三国志·卫臻传》《三国志·刘璋传》《三国志·贾诩传》《三国志·吴主传》《献帝起居注》及《文章志》等。一手材料能够确认的官职标为“确定”；行、兼、转、撤并时点或仅由整理文章推及者标为“推定”“存疑”或“待考”。

二手整理文章作为来源入口，不替代正史：

- [汉献帝建安十八年魏公国肇建，汉朝廷百官梳理](https://zhuanlan.zhihu.com/p/586247272)
- [汉献帝延康元年曹丕践祚前，汉廷末代公卿百官梳理](https://zhuanlan.zhihu.com/p/586525188)
