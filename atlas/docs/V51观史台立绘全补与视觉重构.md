# V51：观史台立绘全补与视觉重构

## 范围

本轮以 V50 为基线，完成默认人物立绘补齐、人物记页面清理和全站“史料工作台”视觉重构。人物范围以 `data/person-source-index.js` 中 `includeInDefault: true` 的稳定 `personId` 为准。

## 立绘资产

- 默认人物：171 人。
- 本轮新增：159 张 V51 立绘；与既有生产资源共同形成默认人物完整索引。
- 统一风格：汉末至西晋绢本设色半身像，清晰显示眼、眉、鼻、口、耳和下颌。
- 资产属性：`interfaceOnly: true`，仅作界面识别，不作为史实肖像或史料证据。
- 立绘索引：`data/person-portraits.js`；运行时清单：`data/portrait-manifest.json`、`data/portrait-manifest.js`；资源目录：`assets/portraits/v51/`。
- 邓艾继续使用 `deng-ai-v2`，旧资源保留为回滚资产。

## 数据门禁与页面

- 移除“默认任官不少于 230 条”的数量硬门禁，仅保留数量统计和数据结构校验。
- 删除人物记页面残余的 V50 设计板、有人脸生产资源、待同步和未生成统计行；后台审计字段保留。
- 新增“史料工作台”共享视觉层：纸张灰背景、墨色正文、朱印红操作色、金色证据提示，兼容移动端和减少动画偏好。

## 验证边界

V51 验证检查默认人物稳定 ID、立绘文件存在性、`ready` 状态、`interfaceOnly` 标记、占位图排除、230 条门禁移除、人物记残余文案清理和便携版同步。立绘生成采用内置图像生成工具，未使用 CLI 或外部图片接口。
