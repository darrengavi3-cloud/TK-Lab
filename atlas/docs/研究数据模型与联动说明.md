# 研究数据模型与联动说明

## 本轮目标

在保留原有地图、职官节点、州镇记录与本地存档的前提下，把三个模块接入同一套研究实体与证据结构；地图现已扩展为十期。当前模型版本为 `schemaVersion: 7`。V7 在 v6 的基础上增加历史时期快照与控制关系断言。

## 统一实体

- 政权 `polity`
- 官职 `office`
- 爵位 `title`
- 人物 `person`
- 任官 `appointment`
- 辖区 `jurisdiction`
- 史料 `source`
- 时期 `period`
- 地图边界 `mapBoundary`
- 沿革事件 `event`
- 时期快照 `periodSnapshot`
- 控制断言 `controlClaim`

旧节点的 `key` 继续保留；新模型另增稳定 `entityId`，避免界面重排或导入合并导致引用失效。州镇任官会补齐 `personId`、`officeId`、`jurisdictionId` 与规范化 `evidence`。

## 兼容迁移

本地缓存、命名存档和完整 JSON 在载入时统一经过 v7 迁移。迁移原则为“保留并注释”：不因字段缺失、名称旧称或史实纠误直接删除用户数据。季汉、蜀汉统一显示为汉；曹魏、孙吴在数据关联层规范为魏、吴。V7 地图证据数据为静态 canonical 数据，不覆盖用户存档。

## 地图沿革事件

郡级快照不再为 200、208、220、228 年分别重复维护完整合并表。`administrative-events.js` 记录“设立年份—设立前归属”，运行时按目标年份推导归并结果，再由十期注册表选择相应州级格局。263 年保留魏汉吴，264 年单列汉亡后的魏吴格局。

当前共纳入 50 条郡级沿革事件，新增南安、新平、庐陵、城阳、东莞、南乡、襄阳、新都、乐陵、西海等建置节点；少量纯几何规范项作为快照例外保留并与史实事件分开。

## 三模块联动

- 点击地图州、郡：显示该年匹配的州镇职任人物，可进入州镇录检索。
- 点击州镇录辖区：切换到最接近该职任起始年的十期地图并高亮辖区。
- 点击州镇录人物：打开人物履历，合并其职官谱任职和州镇录职任。
- 点击史料：打开证据卡，显示来源层级、卷次定位、摘录和研究结论。

## 史实状态

研究结论统一为：确定、推定、存疑、争议。来源层级统一为：一手史料、文档考据、二手索引、地图几何、待核。地图几何可信度继续与国家归属、州制可信度分别标注。

## 自动验收

`verify-research-model.mjs` 验证旧档迁移、稳定实体编号、跨模块人物履历、行政沿革事件推导和十期证据来源完整性；原有验证脚本继续锁定十期地图、夷洲、州郡数量、官制纠误和 405 条州镇记录。
