# V40 文章考据候选层与朝堂公位重构

## 范围

- 建立本地文章候选提取器，正文、注释、作者推断和网页噪声分层保存。
- 西晋九卿、边疆校尉和将军官号保留具体官职，聚合制度只作索引或研究说明。
- 朝堂顶层改为储君之后的公位层，公位内分文官、武官两栏。
- 季汉人物记首批补入八名人物的项目生成头像，并明确标识非史实肖像。

## 资料边界

知乎文章目前按“文档考据／线索与补充考据”登记。正文无法读取时，不用搜索摘要、评论或页面注释替代正文；导入 HTML、Markdown 或文本后，运行 `scripts/ingest-research-article.mjs`，输出仍为 `待核` 候选，不自动升级为确定事实。

西晋官制的正式制度依据仍以《晋书》卷二十四《职官志》为主，任职人物和时间须结合《晋书》本纪、列传核对。骠骑、车骑、卫将军可进入武官公位的视觉层级，但仍分别显示二品等品秩，不能据视觉并列直接推定为同一品级。

## 数据处理

- `data/research-candidates.js` 保存文章来源、候选官职和审计动作。
- `scripts/ingest-research-article.mjs` 只读取本地文章文件，不绕过知乎权限。
- `四征·四镇·四安·四平将军` 保留为官号族说明，不作为单一朝堂席位。
- `西戎校尉` 归入边疆军事职官，后续需按设官、驻地和与雍州刺史的转换分时段核对。
- 九卿总模板不作为朝堂席位，太仆、卫尉、宗正、廷尉、大鸿胪等具体官名单独显示。

## UI 与人物

公位层使用暗红文官、深蓝武官，并附“文／武”标识；卡片底部继续显示具体官品或秩俸。季汉新增诸葛亮、蒋琬、费祎、姜维、刘禅、董允、廖化、张翼八张项目生成头像，均不标记为史实肖像。
