# V7 史料溯源与时期快照

## 目标

V7 不改变现有十期地图的绘制结果，先把地图中的三种信息拆开保存：

1. 正式行政归属：某年州、郡、国的制度性归属。
2. 实际控制与军事影响：曹操、刘备、孙权、关东诸军等在年度节点的主要控制或活动区域。
3. 地图几何来源：现有州郡底稿、后置郡归并和研究示意边界。

因此，地图郡级块数不再直接解释为史实郡国总数；每一个时期快照同时记录来源、置信度和仍需考订的限制。

## 数据文件

- `data/history-evidence.json` 是 V7 的 canonical 数据。
- `data/history-evidence.js` 由构建脚本生成，主页面和嵌入式地图共同读取。
- `data/research-model.js` 的模型版本升为 v7，增加 `periodSnapshot` 和 `controlClaim` 实体。
- `data/research-schema.json` 记录新增字段和受控词表。

## 关键辖区规则

- 雍州必须按时期解释：184、190年不显示；200年仅为河西四郡；220年以后不能倒套200年的河西范围。
- 犍为郡统一归益州系统，名称统一为“犍为郡”。
- 巴郡、巴西郡在对应年份单独保留郡色，不能因政治势力层切换而消失。
- 夷洲是《三国志·吴书·吴主传》所载远征目的地的常驻特殊区域标识，不是吴国正式行政州郡边界。
- 季汉、蜀汉在地图国家标签和研究关联层统一为“汉”。

## 使用方式

形势图顶部“史料校验”打开当前时期的审计面板，显示州数基准、地图郡级块数、几何覆盖、历史断言、来源链接和剩余限制。点击州、郡或夷洲后，地图联动卡片会显示对应辖区的 V7 证据状态；没有单独断言的普通郡，沿用本期快照来源并明确标为“推定”。

## 证据等级

- 确定：有一手史料或明确建置纪年支撑。
- 推定：制度框架明确，但边界由后期几何归并或年度概括得到。
- 存疑：存在多种可能的辖区或控制解释。
- 争议：不同史料或研究传统无法在当前项目范围内合并。

维基百科只作为二手索引和数量基准，不覆盖《后汉书》《三国志》《华阳国志》《晋书》的原始记载。
