# V65 州镇史料收口

## 目标与边界

V65 对当前 533 条州镇原始记录建立一对一审校和发布覆盖，不修改原始 `recordId`，不修改地图文件、坐标或几何。

本轮不把候选表、截图或 Wikipedia 自动升级为史实。`reader-visible` 是发布覆盖结论，`review-only` 保留在审校后台。

原始 533 条按数据集分为：魏 Wikipedia 候选 181、季汉截图表 93、孙吴研究文档 211、V62 西晋原典记录 29、页内核心记录 19。

## 判定规则

1. Wikipedia 只是发现来源。若无与该人、该州郡、该官职匹配的可定位原文，则记为 `discovery-only`、`存疑`、`review-only`。
2. 原典匹配同时校验人名、州名和官职。例如邹岐的《三国志》原文只证凉州刺史，不得被“同名”误用为徐州刺史的证据。
3. 原文只证任职事实时，`matchScope` 明示不自动证明原表的全部起止年。
4. 研究文档中的原典引句与“仅有研究结论”分开登记，但二者都不直接进入读者态。引句必须逐条回到真实原典 URL、定位和上下文，并核对人物、官职与州镇字段后，才能另行升级为 `primary-verified`。
5. 截图表的行号可用于回查候选，但不是原典定位。

本轮同时明确将 `fz_wu_doc_007`、`fz_wu_doc_008`、`fz_wu_doc_016` 三项问题记录固定为 `review-only`，不得由文档引句或无存疑标签自动公开。

## 本轮手工原典核验

页内 19 条原本只有书名或 Wikipedia 来源的记录中，18 条已补一对一原典定位：

- 后汉：刘焉、刘璋、陶谦、刘备、吕布、曹操；
- 季汉：李恢、马忠、姜维四条职任；
- 吴：陆逊；
- 西晋：羊祜、杜预、刘琨、祖逖、陶侃。

其中三条虽可证官职，但不宜发布：

- 刘备：《三国志》此段作“领徐州”，未在此句明称“徐州牧”；
- 刘琨：《晋书》作永嘉元年（307），与原记录起年 306 冲突；
- 祖逖：《晋书》可证奋威将军、豫州刺史，但当前 317 起年未由所引段落确证。

吕范“扬州牧”仍只有 Wikipedia 发现线索，故保持 `discovery-only`。

本轮使用的可定位原典主要包括：

- [《后汉书》卷73](https://zh.wikisource.org/zh-hans/後漢書/卷73)、[卷75](https://zh.wikisource.org/zh-hans/後漢書/卷75)；
- [《三国志》卷01](https://zh.wikisource.org/zh-hans/三國志/卷01)、[卷32](https://zh.wikisource.org/zh-hans/三國志/卷32)、[卷43](https://zh.wikisource.org/zh-hans/三國志/卷43)、[卷44](https://zh.wikisource.org/zh-hans/三國志/卷44)、[卷58](https://zh.wikisource.org/zh-hans/三國志/卷58)；
