# V63 人物可信度与身份注册表

## 目标

V63 将“人物是否存在”与“某个字段是否可公开”分开。附件候选人物的姓名可进入全量名录，但表字、籍贯、生卒、任官和爵位必须分别通过发布门禁。

发布状态只有三种：

- `verified`：可进入读者数据。
- `review-only`：只留在审校数据。
- `suppressed`：不发布且不显示占位文案。

未登记状态的字段在读者态默认隐藏。

## 规范接口

`data/v63-person-registry.js` 导出 `window.SGZ_V63_PERSON_REGISTRY`，核心索引为：

- `byPersonId`：永久冻结的正式人物。
- `legacyToCanonical`：历史 ID 到正式 ID 的单向压平映射。
- `sourceRecordToCanonical`：附件来源记录到正式人物的映射。
- `publicationByPersonId[personId][field]`：字段级发布状态。

`data/v63-reader-people.js` 导出 `window.SGZ_V63_READER_PEOPLE`，只包含 `verified` 字段、兼容 ID 映射和立绘定位。工作簿路径、行号、检索日志、审校候选和 `publicationStatus` 本身都不进入读者数据。统一投影层也显式隔离 `searchState`、`historicalDisposition`、`searchScope`、`finalReview`、工作簿／工作表信息及所有源行定位字段。
