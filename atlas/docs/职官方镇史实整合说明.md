# 职官谱、州镇录与形势图史实整合说明

## 范围与命名

项目核心时段为东汉灵帝时期至西晋灭亡前夕（168—316）。317 年以后的资料不删除，单列“东晋扩展档案”。

三个主模块采用统一的“谱、录、图”命名：

- 职官谱：职官制度、官署、爵位与人物；默认采用左侧层级谱牒、右侧具体官爵与人物卡片的查阅布局。
- 州镇录：刺史、州牧、太守、国相、都尉、都督及其他区域军政职任。
- 形势图：疆域、州郡、城池与战役。

“州镇”是本项目的工作性总称，用来避免把唐以后“方镇”制度倒置到汉魏晋。

## 数据边界

1. 职官谱记录制度中的官名、官署、职掌、秩俸与沿革。
2. 州镇录记录人物、职任、委任称号、辖区、任期、来源层级与置信度。
3. 形势图记录某一时间切片中的政治势力、州郡与战役。
4. 都督诸州军事属于随人、随时、随辖区变化的职任，不再把十九种辖区固定画成常设官署树。
5. 旧版错误节点不直接删除；载入旧工程时改为“纠误归档”或“转入州镇录”，以保护用户数据。

## 本轮主要史实修订

- 东汉与汉不套用曹魏九品官品；停用按官职类别自动推定品级。
- 《通典》魏、晋官品表按具体官名重整；尚书仆射、尚书在魏表列第三品。
- 东汉州牧与刺史分列：州牧二千石，刺史六百石。
- 曹魏删除时代错置的“刑部尚书”，改“邺郡太守”为“魏郡太守／魏尹”，“许县令”为“许昌县令”。
- 汉九卿补宗正；汉中王标为219—221年的称帝前过渡王号。
- 孙吴不再把大都督、左右都护与部督画成固定层级；九卿补廷尉、宗正并保留逐职核证提示。
- 西晋刺史不再统一归在“都督荆州诸军事”之下；“建康令”移出西晋核心树，改列“秣陵令／建邺令”。
- 晋爵制注明魏咸熙元年复五等爵、晋承袭，并分列五等封爵与列侯系统。
- 异族资料拆为“部族内部称号”和“中原王朝护边官署”；以“西域都护／西域长史”替换“大都护”。
- 姜维254—263年的“督中外军事、大将军、降后将军行大将军事、复拜大将军”拆成四段职任。
- 曹魏刺史、都督索引中跨266年的记录拆为魏与西晋两段，原始任期文字保留。
- 《孙吴州郡长官考》导入 212 条有效记录；与既有陆逊荆州牧记录合并一条，项目运行时新增 211 条而不重复显示。
- 文档中 7 条带修订删除号的内容不进入州镇录，另存于 `data/wu-import-audit.json`；每条有效记录保存段落定位与原文摘录。
- 职官与爵位均可在“层级谱牒、架构图、表格”之间切换；爵位切换时不会落入仅适用于官职的表格空视图。
