# V65 将军名号与史书卷次审校

## 目标与边界

本轮关闭两个旧任务：`data/general-titles.js` 中154条 `evidence=待考` 的将军名号，以及人物来源索引中六个“自动扫描零候选、待复核”卷次。结果写入独立审校台账，不直接改写人物、任官、官品、开府或读者页面。

检索底本为2026-08-30访问的维基文库[《三国志》](https://zh.wikisource.org/wiki/三國志)65卷、[《晋书》](https://zh.wikisource.org/wiki/晉書)130卷，并以[《通典》卷36](https://zh.wikisource.org/wiki/通典/卷036)、[卷37](https://zh.wikisource.org/wiki/通典/卷037)复核魏、晋官品名号。精确字符串命中只说明文字出现，必须继续判断政权、年代、授任主体、正文／注层、自称／追赠及项目168—316年时段；不能由命中自动推导常置、品级、开府或某人任期。

`searchState=completed` 只表示本次规定范围已检索，和 `historicalDisposition=确定` 是两个独立状态。“明确无候选”也只表示限定快照内未取得可靠的目标政权候选，不声称所有范围外文献中绝对不存在。

### 关键语境修正

- 季汉“征东将军”的首个命中是后汉马腾，不是季汉任官，结论为“明确无候选”。
- 魏“虎牙将军”与“度辽将军”均已依卷8正文“文帝践阼”后授鲜于辅、阎柔闭合；汉末刘勋、范明友只作比较。“裨将军”增取卷18“文帝即王位”人例。
- 魏“安夷将军”在《通典》命中的是“安夷护军”，没有把词干扩写成将军。
- 魏“积射将军”的《三国志》人例是裴注所载西晋樊震；本条之“确定”仅来自《通典》魏官品段的制度名号，二者已分开保存。
- 季汉“征西、前、后、左、右、军师、翊军”分别由姜维、胡济、吴班、吴壹、高翔、诸葛瞻、霍弋的221年后人例闭合。胡济条是裴注层，未明示引书；吴壹、高翔条是卷40裴注所载诸葛亮《公文上尚书》。
- 吴“前将军”由唐咨、“左将军”由留赞与张布、“镇东”由朱绩、“安东”由徐盛与贺齐的正文人例闭合。“征西”为卷48正文留平；相邻《吴历》注属上一年，不得误归。
- 吴“横江、折冲、抚边、扶义”仅见建国前人例，统一降为“推定”；“绥远”因卷61陆凯人例、“绥南”因黄武元年全琮人例保持“确定”。
- 吴“安南”郭马自号、“平南”廖式自号继续为“争议”。西晋“平西”已由罗尚正式授任闭合，周权自号降为比较命中；“安东”索綝、“安西”司马晃同样升为“确定”。
- 吴“辅国将军”授予自称神人的王表，能证明文字被使用，但不能建立普通人物任官或常置官制。
- 六个“中郎将／校尉／都尉系统”是现代汇总节点，不是史料官名，均标为“排除”。

### 仍需保留不确定性的名号

仅余一条“存疑”：魏牙门将军。三条“争议”为吴安南将军、平南将军、辅国将军。另有20条“推定”，主要是汉末曹氏、刘备或孙氏政权前身人例；在取得建国后同名授任或制度条文前不升级。
