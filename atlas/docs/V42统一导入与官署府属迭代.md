# V42 统一导入与官署府属迭代

## 本次范围

- 建立统一工作簿，覆盖人物、官职、员额、任官、府署、州镇、战事、金石、食货和形势图数据。
- 研究证据字段进入独立的内部证据表；阅读界面继续通过 `projectForReading` 隐藏来源和研究元数据。
- 员额与展示席位分开记录。同一官职的多个员额用多个席位展示，不能用界面席位反推所有时期的制度定员。
- 州主簿、别驾、治中、功曹等州郡属官归入文官；州牧/刺史和太守/国相可从州郡界面进入相应府署页面。
- 金石录展开行显示完整释文；研究状态为争议或存在争议说明的材料在阅读名称前显示 `*`。
- 西域、羌等活动范围的现代边界只作为裁剪和定位参照，不作为古代政区断言。

## 数据导入约定

1. ID 一经发布不可复用；实体关系通过 ID 连接。
2. 未知年份、治所和员额填写“未详”，不得用相邻时期推算。
3. `authorizedCount` 是史料员额，`displayCapacity` 是前台席位容量，两者可以不同。
4. 争议记录使用 `disputed=TRUE` 和 `disputeNote`；前台使用自然语言说明或 `*`，不显示评级徽章。
5. 金石材料的器物年代、墓葬年代、释文和著录分开填写。
