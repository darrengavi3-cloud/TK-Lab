# V59 开府资格与府署考证

## 本轮结论

本轮只处理开府资格、三公府、重号将军府和太子东宫府属。制度资格与具体人物是否实际开府分开记录：

- 东汉《后汉书·百官志一》列大将军、骠骑、车骑、卫将军为“比公者四”，并列将军长史、司马、从事中郎、掾属、令史等“府员职”。这足以建立东汉重号将军府员结构，但不把东汉条文直接改写成魏晋“开府仪同三司”。
- 西晋《晋书》卷二十四明确记载：“骠骑、车骑、卫将军……等大将军，开府者皆为位从公。”因此晋代官名只是可适用的资格类别，只有具体开府、加号或位从公依据时，才启用开府将军府。
- 东汉太子少傅“悉主太子官属”，西晋泰始三年置太子太傅、少傅，咸宁元年置詹事掌宫事。东宫单独建模，不与开府仪同三司混用。

## 待考清理规则

`data/v59-office-evidence-audit.json` 是本轮的逐项台账。已新增的六个府署范围全部为“确定”，每项都具备来源标题、来源定位、来源链接、运行时 ID 和府属角色。

仍需逐条处理的内容没有被隐式升级：

1. 曹魏、季汉、孙吴、西晋的四征、四镇、四安、四平和杂号将军模板，只能说明名号可能出现，不能证明每一时期常置，更不能证明开府；
2. 魏、季汉、孙吴东宫需要分别核对对应《三国志》纪传或官制材料后再建立政权专属府署；
3. 具体人物的实际开府事实，需要稳定 `personId`、`appointmentId`、任期和原文定位同时闭合。

这些项目在 V59 台账中保留为“待复核”，并写明下一步证据边界。没有可靠出处的条目继续显示待考，不用官名词缀、模板或推测年份自动补齐。
