# 观史台 UI 设计契约（V54）

## 视觉方向

观史台是面向史料审校的工作台，不做仿古装饰模拟。V54 的视觉母题是“兰台案牍”：顶部模块像案卷脊签，检索是固定的案头入口，证据状态先于装饰。页面先让用户看懂模块、序位和证据状态，再提供细节编辑。

## 版式规则

- 模块页使用宽内容列，标题、说明和工具栏保持同一左边界。
- 人物记固定为左侧“人物档案／时期快照”双入口；卡片点击只进入人物详情，卡片内不嵌套第二个跳转动作。
- 检索工具栏保留一个主输入框，筛选条件从常用到高级逐级展开。
- 全站只有一个固定“检索”入口；模块内使用“打开统一检索”动作，不再复制检索输入框。
- 政权色只表达政权；文官、武官、州府、军府使用标签和结构，不用随机颜色替代证据分类。
- 立绘是界面识别资产，必须有 `interfaceOnly` 或同等说明，不得暗示为史实肖像。

## 组件状态

按钮、输入框、卡片和抽屉必须具备默认、悬停、键盘焦点、禁用/忙碌和移动端状态。颜色不是唯一状态提示；“待考”同时显示文字。

## V50 设计决定

- 将军名号按曹魏、季汉、孙吴、西晋分别列出；曹魏/西晋按官品，季汉/孙吴按制度序列。疑难杂号保留“待考”。
- 人物立绘首批 50 人优先君主、公卿和军政核心；每张设计稿必须有可辨识五官，但仍标记为界面识别资产，不作为历史肖像复原。
- 未导出生产资源的 Figma 设计稿不得回退显示无五官占位图；人物卡只显示已有人脸生产资源，其他条目标注“立绘设计待同步”或“未生成”。
- 人物统计改为单行紧凑指标带，避免统计卡片在宽屏形成第二行大面积空白；模块品牌统一为“观史台”。

## V51 设计决定

- 全站视觉统一为“史料工作台”：纸张灰底、墨色正文、朱印操作、金色证据提示；不使用强仿古纹理。
- 顶部导航、工具栏、卡片、表格和抽屉采用同一套细边界与低阴影规则，信息层级优先于装饰。
- 人物记不再显示版本设计板和立绘数量状态行；人物卡只呈现人物资料与已接入立绘。
- 所有新增立绘均为带五官的界面识别资产，并标记 `interfaceOnly`，不作为史实肖像证据。

## V54 设计决定

- 主题提供“兰台清昼”“朱批纸本”“青灯夜校”三套语义令牌；政权色不随主题改变。
- 密度提供“舒展／紧凑”，动效提供“标准／减少动效”；偏好只保存为小型界面设置，不进入工程 JSON。
- 按钮分为朱印主按钮、墨线次按钮、轻量幽灵按钮和危险按钮；图标按钮必须有可见焦点和无障碍名称。
- 模块切换、抽屉、卡片只使用有语义的短动效；系统或用户选择减少动效时取消位移、交错和缩放。
- 运行时令牌由 `index.html` 中的 `--v54-*` 变量负责，`DESIGN.md` 是已接受值与语义说明的镜像；主题选择器通过 `data-sgz-theme` 映射到同一套语义令牌。

## V54 反面清单

- 不使用厚重仿古纹理、随机渐变、无限循环动画或 emoji 作为核心工具图标。
- 不用颜色单独表达“待考”、文武属性或证据状态。
- 不把同品官职强行排成未经史料支持的绝对尊卑序列。
