# 中华三国志 · 职官谱本地项目版

打开 `index.html` 即可使用。Vue、Element Plus、GoJS、XLSX、Leaflet、地图脚本、州郡几何和水系数据均已放入本目录；在线底图仍可在联网时启用，断网时不会影响职官谱数据与本地州郡图层加载。

主界面分为“职官谱｜人物记｜战事纪｜州镇表｜金石录｜食货志｜形势图”七个模块。核心史料范围为汉末至西晋（168—316），317 年后的职任资料保留在“东晋扩展档案”。

## 十四期保护规则

以下节点均为必需项并按固定顺序加载：184、189、190、194、199、200、208、219、220、228、263、264、266、280。若注册表缺项、重复、乱序，页面会明确报错并停止载入历史地图。

220 年节点保留但显示为“魏代汉·三国形成期”，不把刘备、孙权提前写成已经建立的汉、吴国家。

199、219 年显示完整郡层与东汉郡名（益州郡、九江郡、涿郡、汉阳郡、河南尹等），219 年跨州郡块按母郡归一；189 年单独保留中平五年分置的南安郡。264 年按咸熙元年分置梁州、永安七年分置广州表达，266 年保留梁州而不提前绘秦、宁、平州；东广汉郡在 264 年后省并广汉。194—213 年的河西雍州按凉州诸将控制表达，不归曹操。

219—263 年曹操／魏的国号大字固定在洛阳附近；郡块点击后可在右侧面板查看县政区并跳转维基百科检索；200—228 年辽东公孙氏按割据势力独立着色。

职官谱地方部分按“州—郡国—县邑”政区层级展示，并据《后汉书·百官志五》《晋书·职官志》补充州郡县属官；州镇表可按州筛选，吴档案任期规范为年份区间；战事纪按时间竖轴显示并支持按战区支线筛选。

地图为十四期分别生成州郡行政快照，不再让 184—228 年复用同一套郡界；新增189年少帝即位过渡图、194年兴平割据图、199年群雄兼并图、219年襄樊之战图，讨董节点按史实保留为190—191年；263 年保留魏、汉、吴，264 年单列汉亡后的魏、吴格局。州郡分色、边界通道、重要战场可独立开关，黄河与长江同时保留“河水”“江水”古称。

根目录原有的 `三国职官谱 .html` 继续作为便携单文件导出版保留，不被项目版覆盖。
