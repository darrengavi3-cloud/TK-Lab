# V35 人物立绘、战事时间轴、爵位与金石录

## 本轮范围

- 人物记：从用户提供的 `4069d2233743dce662a59eb565106442.png` 裁切司马昭、贾充、钟会、荀勖、裴秀、羊祜、何曾、王沈、陈泰九张头像，统一由 `data/person-portraits.js` 管理。头像只在有明确图像索引时加载；政权色用于边框和身份提示，不把立绘风格当作史料证据。
- 战事纪：按年份排序为竖轴，并按“蜀汉与西南、荆襄与江汉、江东与淮南、辽东与北疆、关中与陇右、中枢与北方”分支展示。原有战役、战场和编年条目不改史实内容，只增加展示分组。
- 形势图：首次进入“形势图”模块时才创建地图 iframe，返回其他模块后保留已加载实例，避免启动阶段解析约 3 MB 的地图程序、郡界和水系数据。
- 州镇表：统一替换当前界面、导出标题和审计文案中的“州镇录”；旧版本文档中的历史版本名称保留，以便追溯。
- 金石录：建立灰色待补工作台和空数据表，不预填未经审核的碑刻、墓志、摩崖、砖瓦题记，也不纳入异族材料。

## 爵位史料边界

本轮只落实可由来源直接支持的制度层级，不把人物封爵和具体封地年代批量推断为确定事实：

- 东汉列侯采用县侯、都乡侯、乡侯、都亭侯、亭侯五类；关内侯单列，不与列侯五类混为一谈。
- 曹魏早期承东汉列侯框架；咸熙元年（264）复行五等爵，公、侯、伯、子、男与列侯体系分开表达。
- 季汉、孙吴的预设按东汉列侯框架保守表达；没有来源支持的具体封爵仍标为待考。
- 西晋承魏末五等爵，同时保留县侯、乡侯、亭侯等列侯层级；关内侯单独保留。
