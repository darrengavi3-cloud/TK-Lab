# V37 东汉百官志与金石录框架

日期：2026-08-11

## 本轮范围

- 政权选择器使用“东汉、曹魏、季汉、孙吴、西晋、异族”短标签；保留原有 `han/wei/shu/wu/jin/tribal` 稳定键和正式制度名，避免旧存档失效。
- 新增 `data/han-bai-guan-zhi.js`，以《后汉书·百官志》为一手来源入口，补录东汉尚书台、御史台、中央将军系统及其制度层属官。
- 朝堂谱系继续执行单席位规则：同一官位收束为一个席位，左右丞相等明确并列职位才拆分；无实际储君时使用虚拟待录席位，不伪造人物。
- 金石录升级为空目录模型，新增材料类型、年代、出土地、书体、释文、著录、媒体、来源和研究状态字段；本轮不填入异族材料或未经核定的记录。
- 从用户提供的职官参考图裁切魏国人物参考头像，加入头像索引和人物生平，并以“参考图裁切”标记，不作为历史肖像证据。

## 史料边界

东汉官署节点与官职秩俸优先依据《后汉书·百官志》；曹名、员额、具体置废和任职人物需要按时期继续回查本纪、列传及相关出土材料。将军号、录尚书事、持节和都督职任不混写为固定官署。

金石录当前 `records` 保持空数组。后续每条材料必须有来源、年代状态、著录和争议说明；“待补”只表示目录空白，不表示史实已经确认。

## 资源说明

新增魏国头像来自用户提供的 `4069d2233743dce662a59eb565106442.png` 参考图裁切，资源索引保留 `portraitKind: reference-crop` 和来源说明。头像颜色只表达政权归属，不表达史料可信度。
