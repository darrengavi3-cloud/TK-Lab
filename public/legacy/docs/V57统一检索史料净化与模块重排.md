# V57 统一检索、史料净化与模块重排

## 范围

V57 以 V56 规范源为基线，更新本地运行时和便携版，不提交、推送或部署私密镜像。执行前备份位于 `backups/20260824-pre-v57/`。

## 已实施

- 顶栏统一为“检索＋⌘K”、阅读／审校和“外观”；移除模块内“检索本页”，外观改为约 288px 锚定浮层。
- 职官谱前台只保留朝堂与表格，隐藏思维导图工具和 GoJS 脚本；审校模式下朝堂官位仍打开精确数据案卷。
- 朝堂储君槽位统一显示为“太子”，显示策略把太子置于皇帝下方；汉政权显示名为“后汉”，检索兼容旧称“东汉”。
- 金石录隐藏前台档案层级和核心／扩展／争议徽标，内部 `archiveKind` 与导出字段保留。
- 食货志拆为制度、编年、户口物价三个互斥视图，统计卡不再占用读者版面。
- 研究模型兼容旧字段并输出 `evidenceStatus`、`reviewState`、`uncertaintyReason`、`readerVisibility`。
- `scripts/purge-v57-people.mjs` 对人物源索引执行实体净化：移除 71 个非人物／排除人物记录和 153 条相关任官记录；纠正映射保留稳定 ID 与出处，曹鼎因处于项目范围外不进入活动索引。

## 数据边界

人物实体审核与立绘资源审核分开。`person-v57-runtime-rules.js` 只负责运行时阻断误识别和记录规范化，不作为历史人物证据。误识别立绘不进入运行时人物映射；资源文件本身不因人物净化而删除。

人物源净化后统计：509 个活动人物、766 条活动任官记录、123 个默认人物、177 条默认任官记录。统计由脚本生成，不设置最低数量门禁。表字仍以明确史料为准，缺少可靠出处时前台省略。
