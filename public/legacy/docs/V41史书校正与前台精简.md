# V41 史书校正与前台精简

## 发布范围

V41 以规范项目为唯一源头，依次生成 `public/legacy`、单文件便携版和私密网站副本。发布流程不从派生目录反向覆盖规范数据，也不恢复已经删除的世界背景 pane。

本版的“删除来源和可信度”只针对普通界面与阅读型导出。`schemaVersion: 7` 的规范对象、`evidence`、`source*`、`confidence`、`researchStatus`、完整 JSON 备份和内部纠错表继续保留。

## 校正原则

1. 史实优先级依次为《后汉书》及《续汉书·百官志》、《三国志》及裴松之注、《晋书》相关纪志列传、其他古籍与金石释文。
2. 知乎文章、维基条目和整理文档用于发现人名、官名与卷次线索，不能替代原典定位。
3. 不能确定的年份和职任使用“约某年”“年代未详”“任期未详”“未到任”“一说”等自然限定，不显示评级徽章。
4. 全量检查覆盖结构、ID、国名、年代关系、引用完整性和阅读投影；发现矛盾的高风险条目再回到原典逐项定位。

## 本版明确纠错

- 《三国志·武帝纪》将田租亩四升、户出绢二匹绵二斤之令列在建安九年，故删除 203 年副本，保留 204 年记录。
- 曹操攻徐州造成的人口损失发生在初平四年至兴平元年的两次进军背景中，原 195 年定年无据，改为 193—194 年且具体次序未详。
- 《晋书·食货志》明确泰始四年立常平仓，恢复为 268 年记录并加入编年。
- 《三国志·后主传》注引王隐《蜀记》载炎兴元年汉有二十八万户、九十四万人，带甲十万二千、吏四万，户口记录已回到该卷次。
- 魏明帝复五铢未见确切年份，不再伪定为 227 年；黄初二年复行又罢五铢按同年过程保留，不另造 226 年副本。

机器可读的逐模块纠错结果见 `data/v41-correction-audit.json`。

| 普通界面、搜索、详情 | 不显示 | 不显示 | 保留 |

| 单文件便携阅读版 | 不显示 | 不显示 | 保留 |
