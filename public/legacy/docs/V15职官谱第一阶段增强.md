# V15 职官谱第一阶段增强

## 本轮交付

1. 跨势力官制对照。
   - 职官谱画布上方新增“官制对照”入口；点击后用当前选中官职名检索，或手动输入官职名／别称。
   - 自动匹配东汉、魏、汉、吴、晋官制树中的同名或同别称节点，按势力并排显示品级／秩俸、职权、沿革年代、历任人物与史料出处。
   - 品级、秩俸或职权不一致的字段会高亮为差异色；每条对照可一键定位回对应节点。
2. 结构化沿革事件。
   - 节点详情新增“沿革事件（结构化）”，逐条记录年份、事件类型（设立／更名／复置／改属／裁撤／待考）、说明与史料出处。
   - 与原有自由文本“更名／裁撤沿革”并存；事件随 JSON、多存档、Excel 导入导出一起保存。
3. 编辑草稿暂存。
   - 每次表单提交后自动为对应节点生成草稿；快速切换节点再切回时，属性面板顶部会提示“草稿已暂存”，可一键恢复或清除。
   - 草稿按节点保存，避免撤销、载入存档或误切换后丢失编辑内容。
4. 批量字段编辑。
   - 批量操作抽屉新增“批量字段编辑”：多选节点后可统一设置官职类别、官品、秩俸、符节、从属性质、辖区、开府／遥领／虚职／临时／归档／隐藏，以及追加自定义标签。
   - 未选择字段保持原值；仅官职字段自动跳过爵位节点。
5. 检索升级。
   - 全局检索纳入沿革事件、脚注、证据卡标题／卷次／原文，检索结果按势力分组显示。
   - 新增“限定存在年份”筛选，只显示该年存在（或沿革年份未注明的）官职／爵位。
6. 画布与表格可视化细节。
   - 树形节点左侧色条按领域区分：中央、地方、武职、幕府使用不同颜色。
   - 节点角标增加“中央·文职／武职／地方”等域标识，与虚职、遥领、开府等原有角标并列。
   - 表格总览支持列显隐、按列排序，以及名称、类别、职权、辖区直接内联编辑。

## 验收

- 打开 `index.html#offices`，点击“官制对照”，输入“大将军”可看到多势力并排对照，差异字段高亮。
- 选中官职后添加一条沿革事件，右侧立即出现可编辑事件行；重开页面后仍在。
- 修改节点字段后切换节点再切回，属性面板出现草稿恢复提示。
- 多选节点后在批量抽屉设置“散官”并应用，节点分类立即更新。
- 全局检索输入“大将军”并按 230 年筛选，结果按势力分组显示。
- 表格总览可隐藏列、排序，并直接修改官职名称。
