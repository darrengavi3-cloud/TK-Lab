# V54 职官序位、统一检索与主题重构

## 范围

V54 以 V53 本地缓存配额修复为基线，处理职官谱朝堂排序、四政权武官显示、全站检索入口和观史台视觉主题。规范源保留在本项目，便携版由规范源重新构建；验证通过后同步私密镜像、提交推送并发布私密版本。

执行前备份：`backups/20260823-pre-v54/`。

## 史实与显示边界

- 曹魏常伯显示顺序固定为侍中、散骑常侍、黄门侍郎、给事中。常伯是显示分组，不作为未经出处支持的正式官署名称。
- 秘书监、秘书丞、秘书郎等另列“秘书省”，不因旧分类 `散骑集书` 自动混入常伯。
- “其他”不作为朝堂可见席位。有效地方官迁入地方层，无法确认的条目保留在规范源并进入审校清单，未物理删除史料记录。
- 动态将军名号按 `courtOrder → generalTitleSortOrder → sortOrder → 品级／秩俸` 解析。同品无证据时按并列层级显示，不强造绝对尊卑。
- 季汉不套用魏晋九品；四征、四镇、四安、四平等模板名号保留 `generatedPattern` 和“待考”状态，未核实者不进入默认朝堂席位。中郎将、校尉、都尉的聚合占位保留在审校层，具体官名仍以正史和人物任官记录核对。

## 检索与界面

- 顶部固定一个“检索”入口，支持 `Ctrl/Cmd+K`。
- 人物、战事、州镇、金石、食货模块不再各自渲染输入框，统一通过范围按钮打开检索中心。
- 保留 `searchState`、现有模块筛选状态和跨模块跳转；模块输入值仍可由检索结果动作设置，不清理用户草稿。
- 检索 Enter 处理中文输入法组合态，提供显式清空按钮并恢复焦点。
- 增加“兰台清昼”“朱批纸本”“青灯夜校”三套主题，以及舒展／紧凑密度和标准／减少动效选择。
- 主题偏好与工程缓存分离，避免主题设置扩大工程数据体积。
- 便携版只内嵌默认人物范围实际使用的 123 张立绘，并让人物索引与 manifest 共用一份数据 URI 映射；原图和完整网页资源不变。V54 验证增加 100 MiB 体积门禁，当前产物为 93,473,577 字节。

## 待继续审校

- 《三国志》蜀书、吴书各卷中四方将军和杂号将军的具体人物—年代—官名关系，继续逐条补来源；本轮不把模式生成视为完整编制。
- 同品将军的绝对先后、临时加号和军府所属，仍按具体时期与人物传分别复核。
- “其他”类别中仍有待考条目的最终文官／武官／地方归属，保留审校清单，不静默改类。
