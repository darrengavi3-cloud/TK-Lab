# V52 人物实体纠错与武官名号扩充

## 本轮结论

人物记的错误主要不是“历史人物太多”，而是原始抽取把任官句中的连续文字直接当成姓名：地点、将军号、族属、机构名和句法残片在缺少上下文约束时进入了人物候选；V51 又在实体门禁前为默认候选生成了界面立绘，因而错误条目同时获得了头像。V52 将“原文候选”和“可见人物实体”分开，并把错误资源撤出人物索引。

原始 `rawName`、出处窗口和排除理由仍在 `data/person-entity-audit.json`，可复核；人物卡片和立绘索引不再暴露这些误识别别名。

## 立绘处理

误识别资源没有直接改名冒充其他人物，而是保留原文件并登记进入 `data/portrait-unassigned-pool.json`。本轮从资源池中取出 13 张，分配给已确认但原先没有生产图的有效人物；其余 48 张仍待分配。所有重新分配项都写入 `data/portrait-pool-assignments-v52.json`，并标记为 `interfaceOnly`，避免把随机界面资产误当成历史肖像。
