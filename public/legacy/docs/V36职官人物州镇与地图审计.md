# V36 职官、人物、州镇与 266 年后地图审计

日期：2026-08-11

## 地图结论

当前注册表的 266、280、290、311 年快照没有漏掉 280 年统一后的十九州。266 年只显示建晋当年已设的梁州，秦州、宁州、平州按《晋书·地理志》的设置顺序分别延后到 269、271、276 年，因此不应提前涂入 266 年地图。264 年已处理梁州、广州，280 年已通过十九州名单验证。

当前真正的覆盖缺口是中间年份没有独立地图节点：如果要展示行政沿革的连续过程，可增加 269、271、276 年只读节点；这属于时间轴增强，不应通过修改 266 年快照来解决。

扬州郡级的 280、290、311 年差异已按建置年处理：280 年不提前显示宣城、义兴；290 年补宣城、毗陵；311 年补晋陵、义兴、历阳和江州分置，323 年才出现的永嘉郡不前移。

## 资料处理原则

史籍确定的州制与设置年份进入行政事件模型；几何只表达研究示意。新的公开数据必须同时通过年代、字段、几何闭合、来源许可和项目地图验证，不能因为边界看起来更完整就覆盖已有数据。
