# V50 观史台立绘、人物实体门禁与人物记界面优化

## 范围

本轮以 V49 为基线，处理四类问题：无五官占位图被误当成已完成立绘、产品名称统一、人物记统计区过度占高、人物抽取把官号/地名/句法残片当作人物。

## 人物实体复核

新增可定位的规范化记录：

- “賁九江”→“孙贲”：据《三国志》卷51“策遣賁、景……除賁九江太守”，九江为任职辖区。
- “公女曼”→“曹曼”：据《三国志》卷2裴注“公女曼为长乐郡公主”。
- “康代”→“韦康”：据《三国志》卷25“其子康代为刺史”，此处“代”为代任语法，不是姓名组成部分。

新增实体门禁：常侍大、牧辽东、车骑、左车骑、右车骑、车骑大、伏波、平北、平狄、安东、安北、平东、越骑，以及扶风、桂林、贵阳、江阳等不进入默认人物卡。原始姓名、出处、排除原因仍保留在人物实体审计中。
