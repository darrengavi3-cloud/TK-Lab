# V17 职官谱归类与界面简化

## 本轮调整

1. 归类体系重构为“文臣／武将／中央／地方”。
   - 文臣：三公、九卿、尚书台省、中书门下、御史台、散骑集书。
   - 武将：大将军／大司马、将军武职、都督军事、属国护官。
   - 中央：丞相／相国、宗室诸王、幕府属官、散官、爵禄勋位等。
   - 地方：州牧刺史、郡国守相、县邑令长、部族首领。
2. 分类导航简化。
   - 原“全部／中央官／地方官＋文职／武职／州郡县”双段 chips 改为一行大分类（全部、文臣、武将、中央、地方），每类带势力色点与数量。
   - 选中大分类后出现一行细分类（如文臣下：三公、九卿、尚书台省、中书门下、御史台、散骑集书），未选中时不占空间。
   - 分类切换同时作用于树形图、层级谱牒、表格总览与筛选结果。
3. 画布工具条压缩。
   - “官品体系、官制对照、品秩对照、官署模板”收进顶部“查阅”下拉，不再占一行。
   - 视图切换（谱牒、树形、横向、品秩、表格）改为紧凑分段控件。
4. 筛选条简化。
   - 原“官职类别”下拉移除（由分类导航承担），仅保留搜索、官品、特殊属性和“显示选项”（仅核心体系／显示归档／显示隐藏），并加“重置筛选”。
5. 视觉统一。
   - 树形节点左侧色条、谱牒卡片归类角标、表格“层级”列统一使用文臣／武将／中央／地方的势力配色。

## 验收

- 打开 `index.html#offices`，顶部分类条显示“全部、文臣、武将、中央、地方”，点击“文臣”出现子分类并过滤卡片。
- 点击“三公”仅显示太傅、太尉、司徒、司空。
- 1440 宽度下画布工具条、分类导航、筛选条均无横向溢出。
- “查阅”下拉可打开官品体系、跨势力官制对照、品秩对照、官署模板库。
