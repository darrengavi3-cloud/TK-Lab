# V31 缓存恢复与周边族群矢量层

检查日期：2026-08-06

## 本轮目标

- 消除每次打开页面都必须点击“恢复上次工程”的阻断式弹窗。
- 对 189 年少帝、献帝之际的历史边界继续保留一手史料约束。
- 按参考图补足周边族群的多色矢量区域、浅色边界和地图标签。

## 史实核验

- 《后汉书》卷九记载中平六年四月少帝即位、九月献帝即位；189 年仍是东汉宫廷政变与军队入京的过渡节点。
- 《后汉书》卷七十二记载董卓为并州牧，驻兵河东，灵帝崩后奉何进召率兵入朝；地图中的董卓路线仍是军势叙事，不改成稳定行政疆界。
- 《三国志》卷三十记载乌桓、鲜卑与匈奴活动范围会随汉末至魏初局势变化；乌桓矢量层截到 207 年，其余族群层延续到项目最后的 311 年，仅作为研究示意。
- 189 年的东汉十三州、南安郡建置和“不提前绘制雍州”既有断言保留；没有把周边族群填色并入汉、魏、吴、晋的行政州郡统计。

## 实现

- `index.html`：新增本地会话标记。正常关闭或刷新只保存缓存，不再自动弹窗；检测到上次异常退出时才提示恢复，手动入口仍在“工程 → 从本地缓存恢复”。
- `assets/map/data/strategic-geography.js`：将族群 `pts` 统一标注为 `vectorKind: activity-zone`、`status: 推定`，补充研究说明；乌桓显示期改为 184—207，其余持续性族群延伸至 311 年。
- `assets/map/js/strategic-layers.js`：真正渲染族群多边形，并叠加标签。
- `assets/map/css/style.css`：增加低饱和多色填充、浅色实线边界和文字描边，视觉上接近参考图。
- `scripts/verify-project.mjs`：把旧的“族群多边形不得渲染”断言改为“必须是有研究状态的矢量示意层”。

## 数据边界

族群矢量边界不是正式州郡、国界或精确考古测绘结果；它只表达活动区和域外政权的视觉层级。行政模式关闭该图层，研究示意模式才显示。需要进一步精确到某一年度的部落迁徙、羁縻关系或晋代十六国政权时，应另建带年份与来源的断言，不直接修改当前多边形。
